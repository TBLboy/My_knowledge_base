## Hardware List

| Component | Model | Role | Connection |
|-----------|-------|------|------------|
| 左臂 | xCore AR5-5 07L-W4C1C1 | 黄瓜夹持 / 未来切割 | TCP/IP 192.168.2.160 |
| 右臂 | xCore AR5-5 07R-W4C1C1 | 刀把抓取 + 切割运动 | TCP/IP 192.168.2.161 |
| 左灵巧手 | LinkerHand O6 | 夹持黄瓜/豆腐 | CAN1 (bitrate 1M) |
| 右灵巧手 | LinkerHand O6 | 抓取刀把 | CAN0 (bitrate 1M) |
| 深度相机 | Intel RealSense D4xx | 视觉感知 | USB3 |

## Coordinate Frames

- 右臂 base: X=forward, Y=up, Z=right
- 左臂 base: X=forward, Y=down, Z=left
- 右臂→左臂变换: R_LR = diag(1, -1, -1), T = [0, 0, -0.20]m
