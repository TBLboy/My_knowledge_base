## 0. 任务背景与硬约束（供构思方对齐）

**工作对象**
- **P1**：3-DOF 刚性机械臂，全观测 EL 系统；状态 `[q1,dq1,q2,dq2,q3,dq3]`（6 维），输入关节力矩/电流（3 维），250 Hz。

**目标**：建模与控制器**同时**有真正新意的 Koopman/算子理论路线，保留与算子理论的联系。

**新颖闸门**：① lifting 参数化/辨识目标结构性改变；② 控制器结构性改变；③ P1/P2 物理锚点；④ 可检验新定理；⑤ 方法/定理级先前工作比对；⑥ 现有数据可实现或标注缺口。

**禁止伪创新**：损失权重/注意力/延迟状态/泛化 CBF·tube·自适应·MPC/通用切换·量化·分层·输入变换包装/仅修补证明/把未测量当已知。

**本轮约束**：验证方**只验证 + 反馈，不构思新路线**。

## 3. 第二轮 N1–N6 机制级验证（新）

### N1 — Policy-Equivalent Approximate Koopman（`Δu=Γ_Hδ`，policy-null defect）
- **判定：部分可行，概念被占。**
- 占位：`2603.27677`（Kounatidis–Malikopoulos）证明"**保留控制相关 Hamiltonian 结构而非辨识完整动力学即可恢复最优性**"，给出 **constrained model-plant control equivalence** 条件；`2209.08637`（Uchida–Duraisamy）**control-aware Koopman** 精化闭环行为。
- 实验支持：P2 上不可达缺陷约 **97% 落在 ker(K)**（见 §4.4）→ `prediction error ≠ 0` 但 `policy defect ≈ 0` 成立。
- 风险：`Γ_H` 本质是灵敏度/闭环传递算子（经典）；且闭环下敏感度有界更多来自**稳定性**而非表示性质。

### N2 — Riccati Quotient（`Z/∼_π`，`N_π=Ker(K)`，`N_{π,H}=∩_t Ker(K_tΦ_t)`）
- **判定：换名（bisimulation/闭环降维）+ 平凡化风险。**
- 占位：`2606.09858`（"最粗 action-sufficient 压缩 = **按 policy equivalence 取商**"）；`2509.19266`（**bisimulation** 用于 LQR 闭环）；RL 侧 bisimulation/state aggregation/behavioral equivalence；控制侧 **closed-loop balanced reduction**（Enns 1984；Mustafa–Glover 1990；`2209.07645`）。
- 平凡性：静态反馈下 `Z/ker K ≅ R^m`（P2：m=2；P1：m=3）——**仅瞬时动作等价**，非轨迹等价。
- 实验关键：`ker(K)` **不是 A-不变的**（开环 t=3 敏感度>1），但**闭环 `(A−BK)^t` 下有界** → 必须用轨迹级/闭环定义，否则命题平凡或错误。

### N3 — Policy-Neutral CAP Violation（`Exact ⊊ PolicyLinearizable`）
- **判定：部分可行，需与反馈线性化理论划清边界。**
- 占位：`2602.14537`（精确嵌入 ⇔ CAP）；`2210.05046`（**反馈线性化弱于精确线性化**）；`2211.07112`（Koopman feedback linearization，绕开可控性要求）。
- 待办：给出 Koopman 专属的 `ε_PCAP` 定理，并证明其**不**等价于经典反馈线性化。

### N4 — Policy-Relevant Residual（`r=r_c+r_n`）
- **判定：在 P1 上退化。**
- 实验：P1 状态残差 **100% 落在 im(B)**（位置维残差≈0）→ **`r_n≈0`**，拆分无可用结构（见 §4.5）。
- 占位：控制相关模型降维（`2209.08645`、`2209.08637`）。

### N5 — CAP Obstruction Rank（`C_H=∇_U²F_H`，`rank(C_H)=r≪n`）
- **判定：部分可行，未验证。**
- 需先测 P1/P2 的 `rank(C_H)`；与经典"非线性度/曲率秩"及 `2602.14537` CAP 符号判别区分。

### N6 — Closed-loop Koopman Policy Embedding
- **判定：换名（Koopman 反馈线性化已被占）。**
- 占位：`2211.07112`（Koopman bilinearization / feedback linearization）、`2210.05046`（Koopman-generator 反馈线性化）、`2504.11959`（**闭式闭环 Koopman 特征函数 ↔ 反馈线性化**）、`2604.01730`（应用）。

**N 系列丑角扫描**：
- `all:"policy-equivalent" OR all:"control-equivalent"`：30 命中；`all:"bisimulation" AND all:"optimal control"`：2 命中；`all:"closed-loop model reduction" OR all:"closed-loop balancing"`：1 命中（经典文献奠基）；`all:"feedback linearization" AND all:"Koopman"`：6 命中。

## 4. 廉价证伪实验数据

### 4.1 Test A — R2 前提（gauge）
物理预测对基不变（1.5e-13）；固定 Q 的 LQR 随基变化（condT=1e2/1e4/1e6 → 相对差 0.66–0.83 / 1.3–2.8 / DARE 3-4 失败）。属 1984 已知协变事实。

### 4.2 Test B / B′ — R1 前提（P2 参考可达性）
| H | 一阶…多步 相对缺陷（train mean） |
|---|---|
| 1 | 0.216 |
| 2 | 0.0909 |
| 3 | 0.0326 |
| 4 | 0.00385 |
| ≥6 | ~0（机器精度） |

P2 可控秩 10/10 → 多步可达对 H≥dim 平凡。

### 4.3 Test C — R3 前提（P1 残差可预测性）
AR(1) 改善 24.3/19.4/17.0%（关节 1/2/3）；AR(4) 24.5/20.5/18.6%；ACF lag-5 0.11–0.29。

### 4.4 N-P2 — policy-null 与缺陷投影（检验 N1/N2）
部署模型 n=10, m=2；LQR(Q=I,R=I) → K 秩 2，**policy-null 维数=8**，σ(K)=[61678, 9215]。

| 指标 | train（mean/median） | val |
|---|---|---|
| 缺陷能量占比 policy-relevant (row K) | 0.0267 / 0.0157 | 0.0255 / 0.0153 |
| 缺陷能量占比 **policy-null (ker K)** | **0.973 / 0.984** | **0.974 / 0.985** |
| 缺陷控制敏感度 `‖Kδ‖/(σmax‖δ‖)` | 0.020 / 0.0147 | 0.020 / 0.0144 |

时间不变性（敏感度均值）：

| t | 开环 `A^t` | 闭环 `(A−BK)^t` |
|---|---|---|
| 0 | 0.104 | 0.104 |

**读法**：一步上 ~97% 缺陷 policy-null（支持 N1）；`ker(K)` 非 A-不变（开环 t=3 敏感度>1）；闭环下有界（稳定性主导）。

### 4.5 N-P1 — 残差控制敏感性（检验 N4）
辨识 LTI：ρ(A)=0.9855，rank(B)=3。
- 位置维残差能量（0/2/4）= 5.03e-6（≈0）；速度维（1/3/5）= 0.3145（全部）。
- 残差落在 **im(B)** 的比例 = **1.000**；正交比例 ~1e-16。
- 残差对 LQR K 的控制敏感度 = 0.573。
- **`r_n≈0`**；N4 拆分在 P1 退化。
