## 1. 将可稳定化检查缩到 lifted 维数

固定一个完整学习模型平衡点 (q*,u*)，在该点使用已有导数块：

\[
\mathsf A=\begin{bmatrix}J_z&J_a&J_v\\E_xC_x&S_x&0\\0&0&S_u\end{bmatrix},
\quad \mathsf B=\begin{bmatrix}B_*\\0\\E_u\end{bmatrix}.
\]

r=P-1；S_x,S_u 为幂零移位矩阵。对任意复数 ζ，|ζ|>=1，它们的 resolvent 都存在：

\[
R_x(\zeta)=(\zeta I-S_x)^{-1},\quad
R_u(\zeta)=(\zeta I-S_u)^{-1}.
\]

定义 d×d 与 d×m 矩阵

\[
M(\zeta)=\zeta I_d-J_z-J_aR_x(\zeta)E_xC_x,
\quad N(\zeta)=B_*+J_vR_u(\zeta)E_u.
\tag{S1}
\]

**命题 S-PBH（PROVED）：** 完整线性化可稳定化当且仅当

\[
\operatorname{rank}[M(\zeta),N(\zeta)]=d
\quad\forall |\zeta|\ge1.
\tag{S2}
\]

证明：完整 PBH 矩阵为

\[
\begin{bmatrix}
\zeta I-J_z&-J_a&-J_v&B_*\\
-E_xC_x&\zeta I-S_x&0&0\\
0&0&\zeta I-S_u&E_u
\end{bmatrix}.
\]

用可逆行列消元删除第二、三状态块，秩恰为 rn+rm+rank[M,N]。第三块的输入列使剩余输入列成为 B_*+J_vR_uE_u，正号不可写错。代入完整 PBH 判据即得。

解释：输入历史不仅是额外状态，也通过 J_v 带来延迟输入通路；测量历史通过 J_a 改变有效模态。S2并不意味着可以从预测模型中删掉缓存，只是一个等价的谱域判据。

由于移位幂零，

\[
R_x(\zeta)=\sum_{j=0}^{r-1}\zeta^{-j-1}S_x^j
\]

输入 resolvent 同理。可用 Laurent 多项式表达 S1；乘非零 ζ 的幂不改变 |ζ|>=1 的秩。该检查仍需实际参考点与导数，不能从矩阵范数上界推出满秩。

## 2. 给出一类不能被任何反馈修复的方向

若存在非零复行向量 p* 与 |ζ|>=1，使

\[
p^*J_z=\zeta p^*,\quad p^*J_a=0,\quad
p^*J_v=0,\quad p^*B_*=0,
\tag{S3}
\]

则 p*[M,N]=0，因此不可稳定化（PROVED）。这包括未受输入/历史作用的传播潜坐标不稳定模态；不能把它误认为重复缓存坐标删除。
S3只是容易检查的充分失败条件，不是所有不可稳定模态的必要形式；S2才是完整等价检查。

## 3. 不再假设“周期参考存在”：局部构造方法

选择一个输入严格位于 U 内部的平衡点 (q*,u*)。假设 F 在邻域 C1，且 S2 成立。
由可稳定化性存在常量 K0 使 A0=mathsf A+mathsf B K0 Schur。其构造可用前报告周期LMI的 T=1 情形；本轮未计算具体K0。
选一个周期 T>=2 的小外激励 v_t=v_{t+T}，定义仅用于生成参考的辅助闭环

\[
q_{t+1}=F(q_t,u_*+K_0(q_t-q_*)+v_t).
\tag{S4}
\]

令 Psi_T(q0,v) 为一周期迭代映射。周期边界方程为

\[
\Psi_T(q_0,v)-q_0=0.
\tag{S5}
\]

在 (q*,v=0)，对 q0 的导数为 A0^T-I（此处上标 T 是 T 次幂，不是转置）。A0 Schur 故该矩阵可逆。隐函数定理给出所有充分小周期激励对应的局部唯一周期初值 q0(v)，并由 S4得到完整参考 q_t^ref,u_t^ref。

**命题 S-Ref（CONDITIONAL，条件下解析成立）：** 该参考满足 F 的动力学与全部历史移位等式；平衡输入的严格裕量和有限周期连续性保证足够小激励仍输入可行。参考生成是离线理论过程，不是在线追加一次 rollout 或批准修改执行控制律。

不保证任意指定测量参考可跟踪。所生成轨迹也可能是常量或仅输入非恒定；若要保证观测非恒定，还需至少一个非零激励频率 ω 的线性响应

\[
C_{obs}(e^{i\omega}I-A_0)^{-1}\mathsf B\hat v(\omega)\ne0.
\tag{S6}
\]

C_obs选出当前测量。非零一阶响应使相应小幅激励产生非零观测变化；若S6失败，不能声称构造了非恒定观测参考。

S4传播出的潜坐标不必等于逐时刻编码潜坐标；真实重新编码参考的缺陷仍应计入编码残差。无论如何不能据此声称物理plant可实现该参考。

S6中的频率明确取 omega=2pi k/T，k=1,...,T-1。非恒定观测结论针对固定激励方向 v_t=epsilon vbar_t、充分小且非零epsilon；不保证任意激励有效、最小周期恰为T或全局周期解唯一。

## 4. 从固定点反馈延伸到小周期参考

A0 Schur给出某个P>0与A0^*PA0-P<0。周期参考趋近平衡点时，各时刻完整导数连续趋近mathsf A,mathsf B。因此足够小激励下，同一个K0和同一个P仍满足严格下降（由有限周期、严格裕量与连续性）。
故不必重新假设“存在周期稳定反馈”，即可在上述小邻域继承一个共同反馈证书。但这要求已证固定点可稳定化和C1连续性；现有Lipschitz假设本身不足。

这里固定有限T且允许完整q状态的无结构反馈；若限定测量反馈或稀疏结构，则必须重新检查综合条件。

## 5. 接入非零扰动预算

若进一步有前报告所需的统一DF Lipschitz常数、候选域上的D_fr、首步编码残差传播界和约束余量，则用同一个K0、P进入D7–D10。
参考恰为模型轨道，因此动力学参考缺陷b_t=0；但D_fr、D_init不因此为零。
可稳定化与输入严格内部也不自动保证非零给定扰动下D10可行。必须另外满足判别式和半径截断区间非空；若扰动预算太大，则失败仍只是该证书失败。
