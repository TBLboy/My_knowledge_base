## 1. A2 relative-degree-preserving：输入作用诊断

比较两个线性回归基线：

```text
无当前输入：x_{k+h} ~ [1, x_k]
加入当前输入：x_{k+h} ~ [1, x_k, u_k]
```

这不是 relative-degree 定理，只是检查当前输入是否包含可辨识的预测增量。

### 结果

| horizon h | 无当前输入 RMSE | 加入当前输入 RMSE | RMSE 降幅 |
|---:|---:|---:|---:|
| 1 | 0.148239 | 0.116112 | 0.0321267 |
| 2 | 0.283895 | 0.174287 | 0.1096068 |
| 3 | 0.401977 | 0.198671 | 0.2033053 |

一步模型中输入系数的谱范数约 `0.00339`。由于输入/状态归一化和物理量纲尚未完全锁定，不能把这个数直接解释为物理增益。

### 当前判定

- **确认：** 当前数据中 `u_k` 对未来输出预测有稳定的增量信息；因此“输入完全不可辨识”不是当前 kill 理由。
- **未知：** 这是否满足 relative degree 的定义；当前回归没有检验输出导数、离散差分 rank、输入延迟阶或 lifting 后的 decoupling matrix。
- **未通过：** 尚未证明任何 relative-degree-preserving lifting，也尚未改变控制器结构。
- **下一最小测试：** 定义候选输出 `y=x` 和离散差分阶数，比较 `[∂y_{k+r}/∂u_k]` 的 rank/条件数及跨轨迹稳定性；同时与普通 delay lifting 做严格对照。若没有稳定 rank 条件，A2 kill。

## 2. A7 control-relevant subspace：可控性谱诊断

对部署 checkpoint 的：

```text
C_c = [B, AB, ..., A^9B]
```

计算奇异值。

### 结果

- 数值可控性秩：`10/10`；
- 奇异值：

```text
0.9481, 0.2857, 0.09693, 0.04329, 0.01150,
0.002278, 0.001840, 0.0001395, 5.956e-6, 1.979e-7
```

- 最小/最大奇异值比：`2.087e-7`；
- 相邻奇异值比最大约 `0.808`，没有预先可辩护的“前 r 个保留、其余丢弃”的唯一谱隙。

### 当前判定

- **确认：** 当前 checkpoint 满秩但严重病态；不能使用“秩不足”构造 control-relevant subspace。
- **确认：** 仅凭奇异值排序不能定义 A7 的保留子空间；必须加入 task-error、闭环代价或控制输入能量的可测判据。
- **未知：** 是否存在针对具体任务参考轨迹的控制相关子空间；当前没有定义任务误差投影和控制器合成对象。
- **未通过：** A7 尚未形成可证伪定理或不同于 full-space LQR 的控制律。
- **下一最小测试：** 给定固定 task output/参考轨迹，定义被丢弃坐标对 task prediction/control error 的验证上界，并要求子空间筛选后控制器不再是原 full-space LQR。若只能得到奇异值截断或 PCA，A7 kill。

## 3. 结论

本 spike 不批准 A2/A7，只改变下一步搜索的具体问题：

1. A2 有数据支持“输入影响输出”，但还没有 relative-degree 保持证据；
2. A7 有病态可控性，但没有自然控制相关截断；
3. 如果后续 rank/条件数与 task-error 对照不能产生新控制结构，A2/A7 都应淘汰；
4. 失败后触发 C 级决策：补采能辨识输入延迟/输出相对阶/任务相关状态的数据，或缩小论文范围。
