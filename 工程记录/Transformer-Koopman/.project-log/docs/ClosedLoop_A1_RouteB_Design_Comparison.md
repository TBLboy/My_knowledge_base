# A1 Route B：最小控制器设计比较

日期：2026-10-17；纯理论研究，不实施任何控制器修改。

## 一页决策摘要

**B1** 利用 `bar U_{k+1}=shift(U_k^{fr})+tail` 和 B-EXACT，避免为名义候选重复引入新 Frozen/full 误差；但必须有可离线构造的时变鲁棒终端内缩/不变域。当前没有该设计，因此 B1 为 `CONDITIONAL / OPEN`，不是证明完成。

**B2** 可保存一个已知可行候选并在 QP 失败时执行，但这只保证执行层 fallback，不保证下一 Frozen QP 非空。要升级为 QP 递归可行，仍需 B1 同等的非循环终端证书，因此当前为 `CONDITIONAL / OPEN`。

**优先方案：B1。** 它新增组件最少且保留一次 rollout、一次冻结和一次凸 QP；但当前首要阻碍仍是鲁棒终端内缩域的非空性与前向保持。B2 只作为安全执行保护，不应伪称为 QP 可行性证明。

## B1：shift-tail + 鲁棒终端内缩

在线规则：

\[
U_{k+1}^{shift}=\operatorname{shift}(U_k^{fr})\oplus
\kappa_{k+N}(e_{N|k}^{fr},u_{N-1|k}^{fr}),
\qquad \bar U_{k+1}=U_{k+1}^{shift}.
\]

用真实重新编码初值生成一次下一时刻名义 rollout，并沿其冻结一次；B-EXACT 使该名义候选的 Frozen/full 差异为零，剩余差异来自旧 `D_fr` 对 tail 的影响、旧 full 延长轨迹与真实新初值轨迹之间的 `w_k^xi` 传播以及 tail/参考变化。

新增理论/控制约束：

1. 时变终端外集合 `E_t` 与收紧集合 `E_t^shr`；
2. `kappa_t` 的输入幅值、输入增量和上一输入缓存一致性；
3. 非空时变鲁棒终端内域，对 `D_fr` 和 `D_init` 取 Pontryagin 差；
4. 全时域状态/输入/工作域/调度域余量；
5. 规定名义序列更新并把 QP 可行域限制在证书适用域。

在线结构：一次名义 rollout、一次冻结、一次凸 QP；无在线非凸优化或反复冻结，前提是 tail 为固定仿射/线性规则。

裁决：`CONDITIONAL`。若鲁棒终端内域只能以“每步旧轨迹仍有裕量”定义，则解释力弱并退化为 `OPEN/BLOCKED`。

## B2：可行候选保护/备份

### B2-a：硬终端证书

把终端内域的线性面加入 QP，要求任一最优解保留下一轮证书。若该域是离线鲁棒正不变/时变不变集合，理论上可保持一次凸 QP；若只是额外写入持续 Slater 裕量而无不变性构造，仍是循环假设。

### B2-b：显式备份候选

保存 `U_k^{backup}` 及其可行证书；新时刻先将 shift candidate 作为名义候选。若 QP 无解，执行备份或恢复控制。该机制能改善执行安全性，但“有输入可执行”与“下一 Frozen QP 非空”是两个命题；后者仍需不变域。

### B2-c：离线鲁棒终端管束

用离线辅助反馈和时变管束给出线性收紧，在线只解一次 QP。它最有机会保留凸性，但新增的辅助反馈、状态约束和收紧设计已经是实质控制器变化，需要用户批准，且非空性必须另行证明。

裁决：执行 fallback `CONDITIONAL GO`；QP 递归可行 `OPEN/BLOCKED`，除非 B2-c 提供真正的离线不变证书。

## 逐维比较

| 维度 | B1：shift-tail + 鲁棒内缩 | B2：候选保护/备份 |
|---|---|---|
| 名义更新 | `bar U_{k+1}=shift(U_k^{fr})+tail` | 同一 shift 规则，另存 backup |
| 额外 full rollout | 无；下一次名义 rollout 已是标准一次 | 无，除非验证 backup 的 full 证书 |
| 冻结次数/QP 次数 | 每时刻 1/1 | 正常路径 1/1；恢复路径可能额外检查/求解 |
| 新增硬约束 | 终端内域、全时域收紧、tail/缓存约束 | B2-a/c 需要；纯 B2-b 不一定能保证 QP 非空 |
| 非循环条件 | 离线鲁棒时变不变终端域 | 同等不变证书，或仅执行 fallback |
| 递归可行 | `CONDITIONAL`; 当前 `OPEN` | QP `OPEN/BLOCKED`; 执行 fallback `CONDITIONAL` |
| 时变参考 | 保留，所有集合按绝对时间索引 | 保留，但 backup 必须按参考时间生成 |
| 输入增量项 | shift 后首个增量用实际 `u_{0|k}` 缓存 | 同上；backup 必须携带缓存 |
| 现有控制器差异 | 新终端域、tail、名义规则和可行域 | 另加证书存储、切换/恢复逻辑或管束 |
| 首要风险 | 鲁棒内域可能为空 | fallback 不等于 QP 非空，证书可能循环 |

## 三个压力测试结论

1. 零扰动/零冻结误差：B1 退化为标准时变 shift-tail，但仍需非空终端集合。
2. 非零残差/冻结误差：必须支付 `D_init` 与 `D_fr` 的逐面支持函数；该支持函数不等式只是约束保持条件，不单独证明鲁棒终端集合非空；裕量不足时可能无解。
3. 最优解偏离名义：B-EXACT 只保护名义候选，必须保护整个 QP 可行域或引入硬证书。

## 最终决策

不批准进入 P5。当前首要阻碍是：**没有非循环、非空且前向保持的鲁棒终端内缩/不变域**；同时仍需给出跨采样 `Gamma` 的可计算界、全路径工作域保持和最优解证书。B1 是优先设计方向；B2 只有在升级为离线不变管束时才可能证明 QP 递归可行，否则只能作为执行层保护。
