## A. 项目与任务

- 课题：Transformer–Koopman 机器人控制。阶段②=**论文理论路线重构**：找一条真正新颖的路线，然后在阶段③实现。
- 当前 C 级目标（用户已定，DEC-021）：**首要贡献=控制器设计创新；建模创新可有可无**（建模可直接用标准件）。
- 两个已部署平台（现有数据，无新观测）：

**P1（刚性 3 自由度机械臂）**
- 状态 `x = [q1, dq1, q2, dq2, q3, dq3]`（6 维，全观测），输入 `u` = 3 关节力矩/电流指令。
- 250 Hz，轨迹 ~19.92 s；关节 2 有重力偏置（|mean|≈3.11）。
- 数据：`x(N,6)`、`u(N,3)`，多轨迹。

**P2（4 绳欠驱动连续体，平面光点）**
- 观测状态 `x ∈ R²`（平面点位置），输入 `u ∈ R²` = 命令 `(dx,dy)`；`(R,L,D,U)=(+dx,−dx,−dy,+dy)`。
- Ts ≈ 0.2 s，`|u_max| = 300`；**无张力/绳长/速度/模式观测**。
- 数据：train 70×300、val 20×300、test 10×300。
- 已部署 Koopman 模型：latent=10、`ρ(A)=2.0878`（不稳定）、可控性满秩、`V* = 0`。

**门禁 v0.3（控制器中心，当前生效）** —— 一条路线必须同时满足：
1. 控制器设计有**实质**新颖（非 `B†+固定 LQR`、非通用 MPC/CBF/tube/adaptive/switched/量化/分层/输入变换包装、非改名/加模块）；
2. 在 P1、P2 两个物理锚点上可定义；
3. 有**可检验的定理**（稳定/跟踪/收敛/鲁棒/最优性之一）；
4. 控制器级 prior-art 划界（对照：经典非线性控制 / Koopman 控制 / RL-MPC-learning control）；
5. 建模可用标准件（Koopman 或响应算子均可）；
6. 可在**现有数据**上实现，或声明**最小新增观测**。

**禁止的伪创新**：损失权重调整、多加注意力、延迟状态、通用 CBF/tube/adaptive/MPC、通用 input-transformation 包装、只修证明、把不可测的量（张力/模态/能量）当已知。

### B.2 响应几何的实测事实（第三–六轮 + 本轮）
- **D1**：`V* = 0`（最大 (A,B)-受控不变子空间 ∩ kerC 为 0 维）。
- **D2**：task-family rank 2→10（随任务数）。
- **D3**：有害扰动 q95/full ≈ 0.25/0.24；受控/有害比 ρ≈0.85/0.15。
- **D4**：corr(DWR, ΔJ)=1.0000（线性模型伴随精确，无新意）。
- **D5**：`|u|max ≈ 59–65 ≪ 300`（约束不激活）。
- **D6**：`Δu = B†r` 重构误差 3.7e-12。
- **D7**：一步残差协方差有效秩 90%=2 / 99%=4；Hankel 秩 90%=78 / 99%=97（无低阶动态实现）。
- **P1 局部几何**：corr(u,d) 对角 [0.576,0.405,0.214]；`λmin` 中位 25.8、`λmax` 中位 225；PD **92.6%**，不定 7.4%；∂u 条件数中位 5.4。
- **P2 局部几何**：corr(u,d)=[[−0.611,0.035],[0.041,0.620]]；整流前 PD **0.286%**（几乎处处不定/鞍点）；`σmin` 中位 9.6e-4。
- **P2 整流**：`S0=diag(-1,1)`（**固定常数**）后 `sym(S0 J)` PD **99.67%**；det<0 占 99.78%；特征架 circ std 3.16°；近可积（势梯度 RMSE 0.0188 vs 无约束向量 0.0196）。

### B.3 本轮（第八轮）新增硬约束
1. **谱界**：P2 整流后 μ(q05)=5.5e-4、L(q95)=6.5e-3、**κ(q)=11.8**；但中位区间 κ=**1.67**。P1 μ(q05，PD 子集)=5.13、L(q95)=599.8、κ=**116.8**，中位 κ=**9.07**，PD 90.6%。
2. **开环谱加速失败**：离线 exact-J replay（N=4/6/8，wide/tight 两区间，P1/P2）显示 **Chebyshev 增益从未优于最优常数增益**（Cheb 更优占比 1.3%–37.5%）。原因：wide 区间按构造排除 ~10% 样本、tight 区间排除 ~89%；Chebyshev 带外增长快。
3. **谱信息收益上界很小**：逐窗 oracle 最优常数增益相对全局常数仅快 **1.25–2×**。
4. **响应算子时变显著**：一个 N 步窗内"冻结线性响应"假设不成立。
5. **在线 Jacobian/secant 自适应已被占位**：`arXiv:2606.26188`（连续体臂，Broyden secant + Kalman 在线 Jacobian 补偿）+ 经典 resolved-rate Broyden Jacobian 伺服。

## D. 第九轮请求

**核心判断**：在现有数据上，"迭代逆 / 谱加速 / 在线 Jacobian 自适应"这**一整族控制器设计轴已封闭**（要么在本数据上失效，要么被 prior-art 占位）。

第九轮请二选一并给出可判定路线（≤4 条）：

### 分支① 仍用现有数据，但必须换出"迭代逆/加速"族
请显式指出你的机制**为何不属于**：Newton/quasi-Newton/secant 求逆、Chebyshev/Richardson/多项式开环加速、proximal/resolvent、Anderson、通用自适应/ILC/反馈优化。
可考虑的**未封闭**方向（仅提示，不作限定）：
- 利用**响应算子的多步时间记忆结构**（D7：一步残差秩 2–4，但 Hankel 秩 78/97）设计带记忆的控制器（注意：需与已占位的 D7/残差结构划界）；
- 显式**模型误差/不确定性界定**（用已知 κ、越界比例、整流缺陷）构造鲁棒控制器，而非在线辨识；
- 利用 P1 与 P2 的**结构差异**（P1 强单调 vs P2 需固定输出反射才单调）构造对偶/对称化控制律。

### 每一条路线请给出
1. 一句话机制（**不得**落入 §D 排除族）；
2. 为什么在 P1/P2 上可定义（用 §B 事实）；
3. 可检验定理的**精确陈述**（对象、假设、结论、界的形式）；
