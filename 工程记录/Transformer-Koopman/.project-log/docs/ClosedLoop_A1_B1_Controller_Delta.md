# A1-B1：相对于当前正式控制器的最小设计差异

日期：2026-10-17；仅理论说明；不实施。

## 当前基线

`Main.tex` 控制器：一次名义 rollout，冻结 `bar A_i,bar B_i`，一次 affine-LTV 凸 QP；硬约束只有输入幅值多面体，输入增量目前只是成本项；名义序列选择仍是 implementation choice；无终端状态/工作域硬约束、无 tail 反馈和无可行性证书。

## 必要设计差异

1. 明确参考类别（优先 R1/R3）及绝对时间索引；
2. 正式定义一致性流形上的完整增广转移 `F_t`；
3. 离线构造 `K_t`/`K_t^{last}` 与真实闭环外包；
4. 规定 `bar U_{k+1}=shift(U_k^{fr})+tail`；
5. 构造球形或多面体终端集及非空/前向保持证书；
6. 必要时新增终端面和工作域面约束；
7. 若要限制输入增量，新增真实硬增量约束（改变当前语义）；
8. 证明新 QP 的整个可行域受 T17/A12 证书覆盖。

## 在线结构

若 tail 固定仿射、终端/工作域面线性、证书离线给出，则仍可保持一次名义 rollout、一次冻结、一次凸 QP。任何在线非线性终端优化、重复冻结或失败修复求解都需单独计入复杂度，不能继续隐称原结构。

## 风险和批准边界

以上设计会改变当前 input-only QP 的可行域和语义，特别是终端约束、工作域约束、硬输入增量约束、tail 反馈和名义更新规则。实施前必须用户再次批准。本文件不构成实施授权。
