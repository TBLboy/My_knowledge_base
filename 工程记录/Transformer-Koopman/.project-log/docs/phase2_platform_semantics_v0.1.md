# 阶段② 两平台物理与输入语义（v0.1）

## 1. Geomatric Touch：三自由度刚体机械臂

### 已确认事实（来自用户）

- 3 个自由度；
- 6 个状态变量按关节位置/速度交替排列：

```text
x = [q1, dq1, q2, dq2, q3, dq3]
```

- 输入维度为 3，与三个关节的控制通道对应；
- 这是普通刚体机械臂，不是柔性连续体。

### 尚未确认

- 输入究竟是关节力矩、期望速度、位置增量还是其他低层指令；
- 是否有输入饱和、摩擦、传动比、控制周期和执行延迟；
- 三个输入通道是否近似解耦；
- 是否有已知刚体动力学或质量/惯量参数。

## 2. 软体绳驱光点系统

### 已确认事实（来自 `软控逻辑.txt`）

- 对象是四绳驱动的欠驱动柔性连续体机器人；
- 视觉反馈测量投影平面上的二维光点位置；
- 上位机虚拟控制输入是二维脉冲增量 `v=(dx,dy)`；
- 下位机通过同步差动映射执行四个电机动作：

```text
R = +dx, L = -dx
D = -dy, U = +dy
```

- 控制周期默认约 `0.2 s`；
- 输入受最大速度/可执行时间约束；
- 存在视觉延迟、通信延迟和步进脉冲量化；
- 存在绳索张紧、松弛、临界张紧和安全急停等模式；
- 观测核心是二维光点位置，文档没有证明完整机械状态可测。

### 尚未确认

- 当前训练数据中的 `x` 是否只包含二维光点位置，还是已经包含差分速度/其他状态；
- 四根绳索长度、电机位置、张力是否进入数据；
- `v=(dx,dy)` 是否可视为真实物理广义输入，还是仅为上位机命令；
- 视觉光点到柔性臂真实形态之间是否一一对应；
- 张紧/松弛模式是否有可观测 mode label。

## 3. 跨平台共同结构（目前只标记为研究假设）

两个平台都存在：

```text
外部/虚拟控制命令
        ↓ actuator/interface map
真实执行器动作
        ↓ nonlinear physical dynamics
任务空间观测
```

但二者的状态和执行器物理完全不同。因此不能假设共享同一个机械能、passivity 或动力学结构。

当前最可靠的共同研究对象是：

> **actuation/interface map 与任务空间响应之间的 Koopman 建模关系。**

这只是研究入口，不是已批准理论结论。
