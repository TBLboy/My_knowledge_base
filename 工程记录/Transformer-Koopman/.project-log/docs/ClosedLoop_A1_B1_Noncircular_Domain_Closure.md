# B1：非循环工作域闭合与逐步误差管

2026-10-18。纯理论，无产品改动或数值验证；P5 STOP。
衔接：D1完整增广F、Frozen增广仿射映射、C1–C5终端多面体、W2–W9阶段移位与初始种子。

## 1. 域与证书来源

选择紧凸工作域Omega，输入集合U；F在Omega×U有定义，关于状态为L-Lipschitz。可按绝对时间使用Omega_t、L_t。
这里L须在独立给定域上由模型解析性质认证，不能依赖“实际闭环已安全”。若不可微，直接Lipschitz界即可；不使用二阶余项。
局部二阶余项另需DF在相应状态/输入线段域上Lipschitz；本证明不会把状态Lipschitz升级为Jacobain正则性。

令G_i(q,u)为沿已生成名义轨迹冻结后的增广映射：z块用bar A_i z+bar B_i u，a/v块采用D1相同线性移位。冻结矩阵对本QP固定，G_i对(q,u)仿射，代数上可定义于域外；不会调用域外的非线性调度网络。

## 2. 名义rollout自身的逐步预检

从bar q_0在Omega开始，一步生成bar q_{i+1}=F(bar q_i,bar u_i)。先只在已知合法的当前点求F，再检查bar q_{i+1}是否属于Omega；不属于则本名义序列不能获得证书。
若每步均通过，名义全轨迹合法且冻结矩阵有定义。此为有限次前向包含条件，不是每步QP非空假设。它可以离线对整个初值/名义集合用区间/集合包含认证；本轮未执行该验证。
若部署额外加入在线拒绝/备份规则会改变算法，本报告不批准实施。没有名义预检或覆盖所有可能名义的离线证书时，不能声称自动安全。

## 3. Frozen/full管：不需要下一full状态先合法

令p_i为任意QP候选的Frozen轨迹，x_i为同初值同输入的完整模型轨迹；仅为便于本节证明使用p/x，不是物理测量x。
在当前p_i∈Omega定义局部缺陷

\[
\delta_i=F(p_i,u_i)-G_i(p_i,u_i),\qquad
\|\delta_i\|_2\le\eta_i.
\tag{O1}
\]

eta_i须覆盖相应候选集合。可由调度差的界给出z块缺陷：

\[
[A(c(p_i))-\bar A_i]z_i+[B(C_xz_i)-\bar B_i]u_i,
\]

其余历史块差为零。只需当前p_i和当前已认证名义点；不能要求尚未知的x_{i+1}合法来求eta_i。
给定E_0=0，定义

\[
E_{i+1}=L_iE_i+\eta_i.
\tag{O2}
\]

若Frozen候选满足逐点几何包含

\[
p_i+\mathbb B_2(E_i)\subseteq\Omega_i,
\quad i=0,\ldots,N,
\tag{O3}
\]

则完整轨迹合法且||x_i-p_i||<=E_i。

证明：初值相同。归纳已知x_i,p_i∈Omega_i，于是F(x_i,u_i)存在，且

\[
\|x_{i+1}-p_{i+1}\|
\le L_i\|x_i-p_i\|+\|F(p_i,u_i)-G_i(p_i,u_i)\|
\le E_{i+1}.
\tag{O4}
\]

下一full点的定义只用当前合法点；然后O3在i+1把下一点纳入Omega_{i+1}，没有用下一点来推O4。Omega凸使当前连接线[x_i,p_i]也合法；若L直接对所有点对成立，凸性仅用于需要导数/线段的其他证明。

若Omega_i={q:H_iq<=b_i}，O3等价于线性收紧

\[
H_{i,r}p_i\le b_{i,r}-\|H_{i,r}\|_2E_i.
\tag{O5}
\]

E_i和eta_i必须在QP求解前固定为统一上界；若随候选非线性改变，O5不自动保留线性QP。固定冻结矩阵、L和缺陷包络后，p_i对U仿射，O5为线性面。

这是一条新的局部缺陷证明，不直接复用原K_i的“全部轨迹已在域内”假设；当原K_i自身以轨迹合法为前提时，不能用K_i循环证明其前提。域闭合后可再采用更紧K_i，但旧证据必须重新核对覆盖域。

## 4. 新full与旧移位full的管

令旧完整轨迹X_i已由O1–O5认证；新初值Y_0=X_1+w，w∈W_enc。相同剩余输入与同一个tail下，定义g_0=bar w，g_{j+1}=L_{k+j+1}g_j。
若

\[
X_{j+1}+\mathbb B_2(g_j)\subseteq\Omega_{k+j+1},
\tag{O6}
\]

对j=0,...,N成立（末点使用旧延长X_{N+1}），则对转移索引j=0,...,N-1逐步用当前Y_j与X_{j+1}得到||Y_{j+1}-X_{j+2}||<=g_{j+1}，再由下一O6合法化。包含检查到N，转移仅到N-1，不引入X_{N+2}或Y_{N+1}。
旧延长点X_{N+1}需先由旧终端full点和固定tail生成，并由独立终端域包含认证；不能在证明tail余项前假设其像合法。
对j<N可用X_{j+1}∈p_{j+1}+B(E_{j+1})将O6充分化为

\[
p_{j+1}+\mathbb B_2(E_{j+1}+g_j)\subseteq\Omega_{k+j+1}.
\tag{O7}
\]

对应下一名义序列恰为该shift-tail，新名义full轨迹就是Y。域已由O6证明后才冻结它；B-EXACT于是适用，无须加入新候选冻结误差。

## 5. 终端余项所用线段

D7用到的联合线段为(q_ref+tau(e+d_fr),u_ref+tau K e)，tau∈[0,1]。应独立要求整条线段位于DF正则性认证域，而不是只检查两个状态端点。
若该联合域凸且两端都在其中，则线段条件可由端点包含保证；q_ref+e+d_fr可用Z⊕D_fr外包，u_ref+Ke由输入证书包络。此处只有旧终端当前点和参考点，不要求下一状态先合法。
C5得到下一候选终端，W6/O6再将它纳入下一域；真实plant未来状态不在此论证中。

## 6. 与阶段收紧的联合设计

W4的m_{j+1}>=m_j+epsilon_j保护跨采样候选阶段约束；O5/O7保护误差界自身的适用域，二者不同，不能只保留其中一个。
可先固定一个大的认证Omega，再取安全内部W；要求所有Frozen阶段安全域（含W5深度收紧）满足O5/O7。对于多面体，可把两类面合并为一个预定线性约束族，但必须检查其shift关系与终端末点包含仍成立。
额外收紧可能使问题为空。终端C5与初始W9仅在这些新增面也具有余量时才能接续；不能由“增加安全面”推断仍可行。

## 7. 退出裁决

O1–O7给出非循环归纳顺序：已认证名义点→当前合法Frozen/full点→当前缺陷和Lipschitz传播→下一误差球→下一几何包含。域内连接线与终端Taylor联合线段也单列认证。
解析命题在明示前提下成立；当前项目没有实际Omega、L、eta、残差和面余量证书，故具体B1仍OPEN。无数值验证；本报告不宣布整个理论树或Project Goal完成。
