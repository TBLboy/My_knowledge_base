# A1-B1：本轮发现的证明漏洞与影响

日期：2026-10-17；纯理论审查。

## Issue 1：完整增广映射缺失

**原有接口：** `Main.tex` 给出 `z_{i+1}=A(c_i)z_i+B(C_xz_i)u_i`。  
**问题：** 终端集同时依赖测量历史、过去输入历史、缓存和参考，但没有正式 `F_t(xi,u)` 或其一致性流形 Jacobian。  
**修正条件：** 定义 `X,U^{in},u_last` 的移位转移，并在流形/最小坐标上给出 Jacobian 或真实 Lipschitz 外包。  
**影响：** A2、A3、A4、A6、A7 不能升级为已证明；P5 阻塞。

## Issue 2：有限时域界被误用作终端统一界

**原有接口：** `K_i` 和 A1–A4 是固定有限时域、共同工作域条件。  
**问题：** 它们不自动给出所有闭环时刻、所有终端参考和重新冻结状态的统一 `D_fr/D_enc`。  
**修正条件：** 明确参考类别和前向不变工作域，或给出统一时间索引的扰动外包。  
**影响：** A5/A7/A9 仅条件性。

## Issue 3：输入增量成本与硬约束混淆风险

**原有接口：** `S` 只出现在目标函数。  
**问题：** 不能由成本推出 `Delta U` 硬可行。  
**修正条件：** 若终端证明需要硬增量约束，必须显式新增并记录控制器变更；否则只验证幅值约束。  
**影响：** A8 和输入尾部证书需分支处理。

## Issue 4：候选可行不等于最优解递归

**原有接口：** shift-tail 可作为 warm-start/候选。  
**问题：** QP 最优解可能离开局部证书域。  
**修正条件：** 将终端/工作域线性面加入 QP，证明所有可行解均在证书域；或提供等价的全域证书。  
**影响：** A12/A13 当前 `OPEN/BLOCKED`。

## Issue 5：时变参考类别未限定

**问题：** 任意时变参考可能不可实现或贴近输入边界，使正半径终端集为空。  
**修正条件：** 从 R1 可实现参考或 R3 周期参考开始；R2 必须给统一参考残差和输入余量。  
**影响：** A1 当前 `OPEN/BLOCKED`。

## 总体影响

这些是规格/模型证据缺口，不是当前已证明的结构性不可能。只有在给出完整增广外包并发现不可稳定方向、或扰动需求严格超过所有约束余量时，才能把相应分支升级为真正 `NO-GO`。
