# 阶段② 门禁 v0.3（控制器中心：建模新颖性可选）

- 日期：2026-10-05
- 取代/修订：`phase2_gate_update_v0.2.md`（范式更换）——本文件进一步**把首要贡献轴从"建模"改为"控制器"**。
- 触发：用户 C 级澄清——**真正想做的创新在控制器设计上；建模创新可有可无**。对应 `DEC-021`。
- 背景：七轮（R/N/M/Q/V/W）均以"建模/表示"为优化对象，控制器始终是附带的 `B†+LQR` 或简单逆控制；**控制器设计空间从未被系统搜索**。

---

## 1. 核心变更

- **旧（v0.2）**：首要要求是"建模范式实质改变"。
- **新（v0.3）**：**首要要求是"控制器设计实质新"**；**建模可以是标准/现有的**（现有 Transformer-Koopman，或已刻画的响应算子/单调响应模型），建模新颖性**可选**。
- 不变：证据纪律、失败归因、A/B/C 权限、代码/配置/论文冻结、损失契约定值推迟。

---

## 2. 修订后的门禁（全部满足）

1. **控制器设计实质新颖**：新的控制架构/控制律/算法，**不是** `B†+固定 LQR`、**不是**泛化 MPC·CBF·tube·自适应·切换·量化·分层·输入变换包装、**不是**换名/加模块。
2. **P1 与 P2 双物理锚点**都能落地。
3. **可验证定理/命题**（稳定/跟踪/收敛/鲁棒/最优性/复杂度）。
4. **控制器级 prior-art 划界**：须与 (a) 经典非线性控制（反馈线性化、backstepping、无源/能量整形、contraction）、(b) Koopman 控制（Strässer 综述 2509.02839 等）、(c) RL/MPC/学习控制 显式区分。
5. **建模可用标准件**：Koopman 或响应算子；**不要求**建模新颖。
6. **现有数据可实现**，或显式声明**最小新增观测**（若声明新观测，须给出 Gate：它能解锁什么控制结构）。

**禁止伪创新**（不变）：调损失权重 / 堆注意力 / 加延迟状态 / 泛化 CBF·tube·自适应·MPC / 泛化切换·量化·分层·输入变换包装 / 只补证明 / 把不可测变量当已知。

---

## 3. 供控制器设计者使用的已核实事实（启用性基质）

**P1**：全观测 6 维；响应局部**强单调**（对称部 92.6% 正定，与 M(q)≻0 一致）；index 0、取向 +；残差 **100% 在 im(B)**；无 ckpt。

**P2**：响应**近可积**（势模型 val RMSE 0.01881 ≤ 向量 0.01957）；**局部可逆**（σ_min 中位 9.8e-4>0）；**固定输出反射 `S₀=diag(−1,1)` 后单调**（正定率 0→99.67%）；index 1 / det<0 / 取向 −；条件歧义低（0.21）；2D↔2D 方形响应。

**两平台共性**：输入约束**从不激活**（P2 |u|max≈65 ≪ 300）；现有 Koopman 提升模型**不稳定**（ρ(A)=2.0878，DARE 残差≈1.3e4，见 DEC-018）；**无输出零空间**（V\*=0）；残差动态**全阶**（Hankel 99%=97/100）。

**旧论文缺陷**：`Main34.tex` L719–737 "Schur⇒‖A_cl‖<1" 为假；必须以 `AᵀPA−P=−Q` 的 Lyapunov 范数替代。
