## 2. 第五轮验证结果（本轮核心）

核心判决实验 T5-A/B/C/E（局部响应 Jacobian 的对称部结构）：

**判读**：

- **P1 强单调成立**（92.6% 对称部正定），与你的物理推导 `∂(M⁻¹(τ−b))/∂τ = M⁻¹≻0` **完全一致**。→ V1/V2 在 P1 的物理锚点是真实的。
- **P2 既非正单调也非负单调，而是近乎对称的鞍点**（99.7% 不定；符号翻转也无法挽救）。→ **V1（强单调）死；V2（凸势/梯度场，要求对称半正定 Hessian）死；V3（单调算子，需对称部半正定）死**。
- **P2 的困难不是“模型不够好”**：其响应**近乎确定（歧义 0.21）、近乎可积（curl 0.05）、局部可逆（σ_min>0）**——但**结构（鞍）不满足任何可被漂亮定理利用的性质**。V5 的“部分可观测歧义”前提也被削弱（歧义非主导）。V4 prior-art 极高（你已自认）。V6 超出冻结数据。

**结论：第五轮核心路线 V1/V2/V3 在 P2 上被经验杀死；P1/P2 不能被同一条“可逆单调响应几何”统一。**
