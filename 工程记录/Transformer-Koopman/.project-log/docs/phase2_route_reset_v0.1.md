# 阶段② 理论路线重置 v0.1：旧纠错基线不等于理论创新

> 触发：用户明确否定将“原 Transformer-Koopman + B† 前馈 + LQR 的证明修正”称为理论路线。
> 结论：此前 T1′ / 量化接口 / 有效域命题只保留为**纠错基线与后续安全约束**，不得作为论文中心创新或阶段②最终路线。

## 1. 被降级的旧方案

旧方案本质为：

```text
时序 Transformer lifting
→ 线性 Koopman z+ = Az + Bu
→ B† reference feedforward + LQR feedback
→ 用 Lyapunov metric 修复错误 UUB 证明
```

其数学修正必要，但不构成新的建模方法或控制器：

- Lyapunov-metric UUB 是标准修正；
- 前馈不可达投影残差是该控制律的必然项；
- 量化/饱和与有效域是标准接口/适用范围处理；
- 原模型结构、辨识目标、控制律结构均未真正改变。

**定位：** 该方案只作为阶段③任何候选路线都必须满足的最小正确性基线；不得以此宣称理论创新。

## 2. 新一轮探索的硬门槛

候选必须同时满足：

1. **建模结构改变：** 不能只是 history Transformer 编码后拟合常数 $(A,B)$；须改变状态/输入参数化、operator family、辨识目标或可辨识结构。
2. **控制器结构改变：** 不能只是 $B^\dagger$ 前馈加固定 LQR；须改变控制变量、优化/合成对象、反馈结构或闭环证书。
3. **物理锚点：** P1 的二阶关节动力学与 P2 的视觉部分可观测、离散脉冲差动接口至少各有明确角色；不得用“跨平台共享机械能”这类未经证实假设。
4. **新定理：** 不得只是标准 ISS/UUB/LQR 定理换记号；必须是新参数化/控制结构带来的可检查性质。
5. **prior-art 门禁：** 先全文级对比或至少主论文方法/定理级对比；元数据检索不足以通过。
6. **可落地：** 可在现有两平台数据与阶段③可实现范围内测试；若需新传感器/新采集，先声明为缺口。

## 3. 已知约束与基线

- P1：$x=[q_1,\dot q_1,q_2,\dot q_2,q_3,\dot q_3]$，3 通道关节输入；P2：仅视觉光点 $x\in\mathbb R^2$，2D 整数脉冲命令，经固定四绳差动映射执行。
- P2 没有张力、绳长、速度或 mode 标签；不可把它们当已观测变量。
- 现有 P2 部署模型病态：$\rho(A)=2.0878$，DARE 残差约 $1.3\times10^4$；任何候选都要解决/规避稳定化与数值病态问题。
- 旧 T1′ 修正、$P_G$ 前馈可达性项、稳定化需求（DEC-018）仍有效，但均为**基线约束**。

## 4. 新搜索问题

> 对“P1 的全状态二阶机械系统 + P2 的部分可观测、量化差动软体系统”，能否构造一个**控制相关的共同 operator/observer/controller 结构**，使其建模对象与控制变量都不同于常数 $(A,B)$ Koopman-LQR，并导出一个不是标准 UUB 重述的可验证定理？

## 5. 禁止的伪创新

- 换 loss 权重、加一个注意力模块、加 delay state、加 CBF/tube/adaptive/MPC 标签，但不改变核心结构；
- 只把标准 switched / quantized / hierarchy / input-transformation 控制套在 Koopman 上；
- 只修正原证明错误；
- 把未测张力/模式/能量写成已知状态。
