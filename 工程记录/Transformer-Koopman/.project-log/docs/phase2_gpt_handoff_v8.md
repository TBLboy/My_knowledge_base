## 3. 门禁 v0.3（控制器中心，全部满足）

1. **控制器设计实质新颖**：新架构 / 新律 / 新算法，**不是** `B†+固定 LQR`、**不是**泛化 MPC·CBF·tube·自适应·切换·量化·分层·输入变换包装、**不是**换名/加模块。
2. **P1 与 P2 双物理锚点**都能落地。
3. **可验证定理/命题**（稳定/跟踪/收敛/鲁棒/最优性/复杂度）。
4. **控制器级 prior-art 划界**：与 (a) 经典非线性控制（反馈线性化、backstepping、无源/能量整形、contraction）、(b) Koopman 控制（Strässer 综述 2509.02839 等）、(c) RL/MPC/学习控制 显式区分。
5. **建模可用标准件**（Koopman 或响应算子），不要求建模新颖。
6. **现有数据可实现**，或显式声明**最小新增观测**并给出它能解锁的控制结构。

**禁止伪创新**（不变）：调损失权重 / 堆注意力 / 加延迟状态 / 泛化 CBF·tube·自适应·MPC / 泛化切换·量化·分层·输入变换包装 / 只补证明 / 把不可测变量当已知。
