### 2.2 现有方法（论文当前所写的方法）
- **【确认】** 建模流程：
  - 历史窗口 $X_k=[x_{k-P+1}^\top,\dots,x_k^\top]^\top\in\mathbb{R}^{P\times n}$，$P=8$；
  - 切成 patch（$p=2$，$N=4$ 个 token）→ 共享线性嵌入 + 正弦位置编码 → $L$ 层自注意力 → **mean pooling** → 投影得 $h_k\in\mathbb{R}^{d-n}$；
  - 提升状态 $z_k=[x_k;h_k]\in\mathbb{R}^d$；固定解码 $x_k=Cz_k$，$C=[I_n\ 0]$；
  - 线性 Koopman 动力学（**常数矩阵**）：$z_{k+1}=Az_k+Bu_k$。
- **【确认】** 训练三阶段：
  - Stage0：EDMD ridge 热启动 $\Theta=(Z^+)^\top\Omega(\Omega^\top\Omega+\lambda I)^{-1}$；
  - Stage1：五项损失联合优化（$L_x,L_z,L_c,L_{multi,x},L_{multi,z}$）；
  - Stage2：固定编码器，ridge 重拟合线性部分。
- **【确认】** 控制器：
  - $u_k=u_{ff,k}+u_{fb,k}$；
  - 前馈 $u_{ff,k}=B^\dagger(z^{ref}_{k+1}-Az^{ref}_k)$；
  - 反馈 $u_{fb,k}=-K_c e^z_k$，$e^z_k=z_k-z^{ref}_k$；
  - $K_c=(R+B^\top PB)^{-1}B^\top PA$，离散 LQR，$Q=\mathrm{diag}(Q_x,\alpha I)$。
- **【确认】** 配置规模：
  - P1：`state_dim=6, control_dim=3, latent_dim=64, history_length=8, patch_length=2, n_layers=3, d_model=128`；
  - P2：`state_dim=2, control_dim=2, latent_dim=10, history_length=8, patch_length=2, n_layers=1, d_model=16`。

### 2.3 两个平台

#### 平台 1（P1）：三自由度刚体机械臂
- **【确认】** 3 个自由度；状态 6 维，按关节位置/速度交替排列：$x=[q_1,\dot q_1,q_2,\dot q_2,q_3,\dot q_3]$。
- **【确认】** 输入 3 维；**输入语义 = 关节力矩/电流指令**（项目方确认）。
- **【确认】** 采样率 **250 Hz**（$\Delta t=0.004$ s），单条轨迹约 19.92 s。
- **【确认】** 第 2 关节力矩有明显正偏置（`absmean≈3.11`，范围 `-0.21~5.71`），与含重力补偿的力矩指令一致。
- **【确认】** 速度列与位置数值微分的相对误差为 6.8%/11.3%/16.2%（说明速度是真实测量而非严格数值微分）。
- **【确认】** 数据量：train 15 条（74655×6）/ val 4 条（19909×6）/ test 1 条（4976×6）；`u`=(N,3)。
- **【确认】** **没有 P1 训练 checkpoint**（结果目录为空）。

#### 平台 2（P2）：柔性绳驱光点系统
- **【确认】** 四绳驱动的欠驱动柔性连续体机器人。
- **【确认】** 视觉反馈只测量投影平面上的 **2D 光点位置**。
- **【确认】** 上位机命令 $v=(dx,dy)\in\mathbb{R}^2$；下位机用**固定差动映射**执行四绳：$R=+dx,\ L=-dx,\ D=-dy,\ U=+dy$。
- **【确认】** 控制周期约 0.2 s（可用约 0.15 s）；$|u_{\max}|=300$ 步；张紧由初始“临界张紧”标定保证；**共模（$R+L$、$U+D$ 同向）从不下发**。
- **【确认】** **无张力、无绳长、无速度、无 mode 标签**。
- **【确认】** 数据量：train 70 条 / val 20 条 / test 10 条，每条 300 点（约 0.2 s/点）；`x`=(N,2)，`u`=(N,2)。
- **【确认】** 唯一可用的部署 checkpoint：`platform2_full_model.pth`，含 `koopman_A`(10,10)、`koopman_B`(10,2)。

### 2.4 论文当前的已知问题
- **【确认】** 定理声称“Schur 稳定 $\Rightarrow \|A_{cl}\|<1$”，是伪推理。反例：$A=\begin{bmatrix}0.95&3\\0&0.95\end{bmatrix}$，$\rho=0.95$ 但 $\|A\|_2=3.2755$。
- **【确认】** 误差动力学遗漏前馈不可达项 $-(I-BB^\dagger)(z^{ref}_{k+1}-Az^{ref}_k)$。
- **【确认】** 旧界 $\varepsilon/(1-\|A_{cl}\|)$ 分母可为负。
- **【确认】** 实验章节为空。

## 4. 可复现证据与关键量测

### 4.1 P2 部署模型（导出 checkpoint）的线性诊断
- **【确认】** $A\in\mathbb{R}^{10\times10}$，$B\in\mathbb{R}^{10\times2}$；$\rho(A)=2.08776$；$\|A\|_2=25.5154$；$\|B\|_2=0.01992$。
- **【确认】** 可控性矩阵 $[B,AB,\dots,A^9B]$ 数值秩 **10/10**；奇异值由 0.9481 递减至 1.98e-7。
- **【确认】** 取输出映射 $C=[I_2,0]$：可观测性矩阵数值秩 **10/10**；条件数约 **9.44e8**；三个单位圆外模态的 PBH 秩均为 10（数值上可检测）。
- **【确认】** 输出相对阶为 **1**：$CB$ 满秩，条件数 1.13。
- **【确认】** LQR（$Q=I,R=I$）得到的闭环 $\rho(A_{cl})=0.999958$，DARE 残差约 $1.3\times10^4$，$\mathrm{cond}(P)\approx2.2\times10^{10}$。
- **【确认】** `metadata.history_length=4` 与配置 `history_length=8` 不一致；配置 `svd_clipping=false`（未强制谱半径上界）。

### 4.2 P2 动作数据审计
- **【确认】** 训练动作样本 30000；**唯一动作向量 = 30000（全部唯一）**。
- **【确认】** 动作 **不是整数**：精确整数比例 0%；距最近整数最大误差约 0.5。
- **【确认】** 长度 1/2/3 的动作前缀重复次数全部为 **0**。
- **【确认】** 结论：现有 P2 数据不支持需要“动作前缀支持/条件分布”的离线方法。

### 4.3 P2 最小建模对比
- **【确认】** 常数输入模型 affine：val RMSE `0.116112`；
- **【确认】** 一阶状态-输入耦合 bilinear：val RMSE `0.116048`；
- **【确认】** 两者几乎无差异（MAE 还略差）。

### 4.4 P1 结构化建模与残差诊断
- **【确认】** 常数对称惯量 EL 模型：可辨识出 **正定** $M$（特征值 0.000755 / 0.001469 / 0.002161，条件数 2.86）。
- **【确认】** 富 EL 模型（含 $M(q)$、科氏/离心、库仑摩擦，75 块）val RMSE 每关节 0.344 / 0.421 / 0.260，约等于力矩标准差的 **0.37~0.48**（近 R²≈0.77~0.86）。
- **【确认】** 残差结构：滞后 1 自相关 **0.56~0.65**（非白噪声）；与加速度≈0；与速度弱相关（0.17~0.27）。→ 判定为**结构化未建模动力学**。
- **【确认】** 手工物理特征 lifting（`[1,x,sin q,cos q,dq²,u]`）相对原始 affine：val RMSE 0.22556 vs 0.22293，几乎无收益。
- **【确认】** 采样率 250 Hz，因此加速度可用数值微分得到，但速度可能存在量化噪声。

## 6. 已尝试的技术方向与观测结果

> 以下为项目在探索过程中**已经评估过**的方向及其观测结果，按“淘汰/降级原因”归类。此处仅记录事实，不代表任何方向不可行之外的判断。

### 6.1 因数据限制被淘汰
| 方向 | 观测结果 |
|---|---|
| P2 预测状态表示（PSR）+ 离散 pulse planning | 动作前缀无重复（30000 全唯一）、浮点非整数 → 无动作支持 |
| P2 奇异摄动/分层 | 无快变量、无时间尺度分离证据 |
| P2 切换/多模型 Koopman | 无 mode 标签 |
| P2 随机 Koopman + Wasserstein/DRO | 无重复试验/无分布样本 |
| P1 闭环性能感知辨识 | 无真实闭环数据 |

### 6.2 因“与现有方法等价/标准理论”被降级
| 方向 | 观测结果 |
|---|---|
| P2 延迟嵌入 + 输出反馈 LQR | 与现有 history lifting 等价；已有直接先例 |
| P2 Koopman 观测器 | 标准 Luenberger 结构；可观测条件数 9.44e8 |
| 量化/延迟/饱和接口处理 | 成熟理论移植 |
| 联合 Lyapunov/CLF 证书 | 标准结论；二次 CLF 对学习式 bilinear Koopman 被证常不存在 |
| 不变性缺陷界 | 标准误差界理论 |
| 残差观测器/扰动补偿 | 标准 DOB/ESO |
| 切换 Koopman + 公共 Lyapunov | 标准切换系统理论 |

### 6.3 因“prior-art 已有直接工作”被淘汰
| 方向 | 相关已存在工作（示例） |
|---|---|
| EL/机械臂广义动量 Koopman（P1 对应结构） | arXiv:2509.17010（2025-09 / v2 2026-02）：动量结构 + 已知线性驱动通道解耦 + GESO |
| 数据驱动反馈线性化 | Gadginmath/Krishnan/Pasqualetti, IEEE TAC 2024（10.1109/tac.2024.3417188） |
| 输入条件 operator family / LPV-Koopman | Haseli/Mezić/Cortés CDC 2025（10.1109/cdc57313.2025.11312881）；Cisneros IFAC 2020；Chen CDC 2024 |
| 可控性保持 Koopman 表示 | ICLR 2026（OpenReview jITPFROpWN） |
| Koopman 观测性 / output-canonical EDMD | Park & Hwang CDC 2024（10.1109/cdc56724.2024.10886269） |
| 变换域不变性缺陷/误差界 | Conradie et al. arXiv:2603.15091（2026） |
| Koopman 残差观测器 | arXiv:2605.07318（2026）；软臂残差 Koopman（IJRR/NASA 2025） |
| Wasserstein/DRO LQR | Taşkesen/Kuhn NeurIPS 2023；Hoffman 2025 Koopman+DRO-MPC |
| EL Koopman 事件触发 | Zheng et al. CDC 2024（10.1109/cdc56724.2024.10886671） |

> 说明：上述 prior-art 的多数判断来自摘要/元数据层面，**尚未做全文级方法/定理对拍**。

### 6.4 已做最小实验但未通过的候选
