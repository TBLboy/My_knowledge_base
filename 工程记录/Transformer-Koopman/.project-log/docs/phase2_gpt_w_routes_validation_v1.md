## 2. 对第五轮结论的修订（我方表述澄清）

第五轮报告曾写：

> "符号翻转也无法挽救，因为 `SJS` 保持不定。"

**这是关于双侧共轭（congruence）的陈述，对"我只改输出坐标"这一问题不适用。** 若只重定义输出 `d̃=Sd`（输入 u 不变），Jacobian 是 **`J̃=SJ`**，其对称部为 `sym(SJ)`，而 `sym(S₀J)` **可以正定**。对一个近似对称、签名 (1,1) 的 J，取 `S=Q diag(1,−1)Qᵀ`（Q 为特征架）总能使 `sym(SJ)≻0`；由于 P2 特征架几乎不变，**一个常数 S₀ 就够了**。

**修订后的正确陈述**：P2 的标准配对下**不是**单调映射；但在**固定的输出取向**（`S₀=diag(−1,1)`）下**是**单调映射。因此第五轮"P2 被结构性杀死"应改为"**P2 需一次固定的输出轴反射即满足单调性**"。

这也意味着：**第五轮 V1 的技术结论（"P2 response 不可单调化"）被推翻**；V1 的单调前提在 P2 上**成立（差一个常数符号约定）**。但——见 §4——这不带来新颖性。

## 3. 对第六轮 W1–W6 的判决

- **W5（signature rectification）**：**证实**——且只需常数 S₀，GPT 自己已预判"若常数 S 即可则不够新，但会修正事实库"。**属事实修正，非贡献。**
- **W1（Morse-indexed）**：前提（index 1 稳定、近可积）**成立**，但既然常数反射即可单调化，真正的结构是"**单调（固定取向）+ 近可积**"，比 Morse/saddle 机械**更简单**。Morse 语言在这里是**过度包装**。
- **W2（saddle inverse）**：**前提消解**——不是真 saddle，无需 min–max。
- **W3（degree atlas）**：degree 稳定为 −1、局部已可逆 → 证书平凡；延续算法本身非新。
- **W4（polar factorization）**：**前提消解**——近可积 + 常数反射单调，无需 Brenier 分解。
- **W6（Morse–degree continuation）**：建立在被消解的鞍前提上 → 过度机械。

**第六轮无新路线。**

## 4. 修正后的事实库（跨六轮）

| 平台 | 控制响应 `u→d` 的结构 |
|---|---|
| **P1** | 单调（对称部 92.6% 正定）、残差 100% 在 im(B)、index 0、取向 + |
| **P2** | **近可积（势模型不损精度）**；局部可逆（σ_min>0）；**固定输出反射 `S₀=diag(−1,1)` 后单调（99.67%）**；index 1 / det<0 / 取向 −；条件歧义低（0.21） |

**新统一陈述**：两个平台都具备**单调（P2 差一个固定输出轴反射）、近可积、局部可逆的控制响应算子**。P2 的"非单调"是**一个常数取向约定**，不是不可塑的鞍 obstruction。

**但这不构成新理论路线**：其核心仍是"单调响应 + 逆控制"，而该机制**已被 inverse-dynamics / monotone-operator 文献高度占据**（第五轮已判）。常数反射是记号约定，不新。
