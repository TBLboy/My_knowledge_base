## 0. 结论先行

## 1. Z0（NFATSR 不可能性）—— 数值确认

对 `e_{k+1}=(I-α_k J_k)e_k`，`J_k∈[μ,L]`，允许 adversary 在看到 `α_k` 后选 `λ_k∈{μ,L}` 最大化 `|1-α_k λ_k|`：

| 平台 | κ | const 对抗 N=6 | Chebyshev 对抗 N=6 | 理论 (q*)^6 |
|---|---|---|---|---|
| P2 | 12.22 | **0.3738** | 33.41 | 0.3738 |
| P1 | 114.25 | **0.9003** | 335.21 | 0.9003 |

- 常数增益 `α*=2/(L+μ)` 的对抗收缩**精确等于理论 `((κ-1)/(κ+1))^N`**（minimax 达到）。
- Chebyshev 在对抗时变下被放大 **89×（P2）/ 372×（P1）**。

**判定**：Z0 **数学正确且与第八轮 Y3 replay 一致**。它解释了"为何固定多步加速器在真实时变响应上天然失效"，并给出边界：**固定多步谱加速在 time-varying sector 下无 minimax 收益；最佳常数增益已是因果标量增益类的 minimax 最优**。

**novelty 评估（重要保留）**：Z0 的证明是初等的（逐步 max + 乘积下界），且与 regret-optimal control（`arXiv:2304.14835`）、经典鲁棒控制相邻。**作为独立主定理偏薄**；宜作为"表征/不可能性论文"中的一节，而非唯一贡献。

## 2. Z1（ERCRC 误差回收剪切反馈）—— 被否

actual-J replay（现有数据局部 Jacobian，N=10），比较最优常数 / naive clip / ERCRC（剪切半径 `τ=β·α`）：

| 平台 | 策略 | q50/q95/q99 跟踪误差 | max‖Δu‖ | 记忆 |
|---|---|---|---|---|
| P2 | const | **0.0042 / 0.0266 / 0.0462** | 282.3 | — |
| P2 | naive clip (β=.5) | 0.0062 / 0.0355 / 0.0568 | 140.9 | — |
| P2 | **ERCRC (β=.5)** | 0.0260 / **0.1923** / **0.3596** | 140.9 | 均值 2.91 / max **281.2** |
| P2 | ERCRC (β=1,2) | 同 const（未触发剪切） | 282 | 0 |
| P1 | const | **0.0433 / 0.2041 / 0.3563** | — | — |
| P1 | **ERCRC (β=.5)** | 0.1022 / **0.4753** / **0.6796** | — | max 0.0124 |
| P1 | ERCRC (β=1,2) | 同 const（未触发） | — | 0 |

**判定：KILLED**——一旦剪切激活：
1. 尾部误差**显著变差**（P2 q95 0.192 vs 0.027，P1 q95 0.475 vs 0.204）；
2. 记忆**持续积累**（max 281，破坏"有界记忆"假设）；
3. naive clip 同样不优。
即 GPT 自设的三条 kill 判据**全部命中**。机制原因：剪切拖慢好步收敛，回收又在后期注入被放大的修正，净效果是放大而非抑制尾部。

## 3. Z2（REIC 逆命令鲁棒聚合）—— 被否

对局部线性响应做 bootstrap（B=25，k=300），比较单模型 / 均值 / 坐标中位 / 几何中位 的逆命令误差（相对记录的真实 `u`）：

| 平台 | single q50/q95 | geo_median q50/q95 | 改善 |
|---|---|---|---|
| P2 | 138.12 / 408.93 | 131.49 / 396.33 | ~4.7% / 3.1% |
| P1 | 3.596 / 6.056 | 3.613 / 5.908 | ~-0.5% / 2.4% |

**判定：KILLED**——改善远低于 GPT 自设的 20% 门槛。逆解失败高度相关（同一 context 下 bootstrap 方差小），鲁棒聚合无法抑制。且 prior-art（geometric median / robust aggregation / trimmed-mean）极为成熟。

## 5. 总体判定与累积封锁链

第九轮后，现有观测下的控制器搜索形成完整封锁链：

1. 响应 bulk 强单调（P2 固定输出反射后 99.67%）；
2. 约束从不激活（`|u|max 59–65 ≪ 300`）；
3. 无输出/任务零空间（`V*=0`）；
4. 无低阶残差动态（Hankel 秩 78/97）；
5. Newton/quasi-Newton/secant 逆已被占（2606.26188）；
6. 多项式/谱加速被时变性杀死（Z0 + Y3 replay）；
7. sector-only 下最佳常数增益已成 minimax 最优（Z0）；
8. 尾部鲁棒误差回收无效（Z1）；
9. 逆命令鲁棒聚合无效（Z2）；
10. robust inverse/DLS、IQC/H∞/圆判据、funnel/sliding、conformal 均属经典方法（门禁排除）；
11. 新增观测被用户禁止（DEC-022）。

→ **正式结论**：**在当前观测 + 当前门禁 v0.3 下，不再存在有经验动机的非经典控制器路线。**
