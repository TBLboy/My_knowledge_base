# 阶段② 门禁 v0.2（依 C 级决策 D：更换建模范式）

- 日期：2026-10-05
- 取代关系：本文件**修订** `phase2_route_reset_v0.1.md` 的门禁条款，仅就“建模范式”一项放宽；其余证据纪律不变。
- 触发：用户 C 级决策 **D（更换建模范式）**，对应 `DEC-020`。
- 背景：跨四轮（R18/N6/M12/Q7）在“必须保留有限维 Koopman 线性闭合”前提下无候选存活。

---

## 1. 被修订的条款

- **原（DEC-015）**：阶段② 必须保留与 Koopman/算子理论的联系。
- **现（DEC-020）**：**不再要求**建模范式必须是有限维 Koopman 线性闭合。允许：
  - 其他算子/表示骨架（如 contraction、LPV、带低维非线性核的混合模型、耗散/无源、可解释残差动力学等）；
  - 范式层面的重构，而非在 Koopman 内换皮。
- 但“放宽范式”不降低证据要求：必须**显式论证该范式对本平台是必要的**，并说明有限维 Koopman 闭合为何失败（用下列四个已证事实）。

---

## 2. 修订后的门禁（全部满足）

1. **范式或建模参数化发生实质改变**：允许非 Koopman 骨架，但须给出“为何本平台需要该范式”的论证，且**显式回应**第 3 节的四个经验事实。
2. **控制器结构随范式改变**：不是 `B† + 固定 LQR` 换皮。
3. **双物理锚点 P1 与 P2** 都能落地。
4. **可验证的新定理/命题**（稳定/收敛/误差界/复杂度/可识别性等）。
5. **方法/定理级 prior-art 划界**：须同时与 (a) Koopman 阵营近期工作、(b) 经典非线性控制（反馈线性化、eigenstructure assignment、最小实现、immersion 等）显式区分。
6. **现有数据可实现**，或显式标注数据缺口并给出**最小必要传感集**（允许在“更换数据/平台”的前提下提出）。

**禁止的伪创新**（不变）：调损失权重 / 堆注意力 / 加延迟状态 / 泛化 CBF·tube·自适应·MPC / 泛化切换·量化·分层·输入变换包装 / 只补证明 / 把不可测变量当已知。

---

## 3. 必须回应的四个经验事实（来自 T4 实验）

1. **P2 闭合误差小且不可后验重塑**：冻结 lifting 下，状态反馈乃至 rank-10 全秩非线性漂移仅降 val RMSE 0.25%，残差有效秩不变（2/4）。
2. **P2 obstruction 无低阶动态**：残差块 Hankel 秩 99%=97/100；第三轮 D7 的“低秩”仅是瞬时协方差。
3. **P1 残差恒在 im(B)**：秩 3、100% 在输入通道；非线性 prefeedback 降 RMSE 31% 但秩不变（=标准输入通道辨识）。
4. **P2 受限**：V\*=0、任务族秩满、约束从不激活、30,000 动作全互异（无离散 PSR）。

任何新范式路线必须说明：它在**哪个环节**绕过了这四条限制，或明确指出需要更换数据（第 6 条）。
