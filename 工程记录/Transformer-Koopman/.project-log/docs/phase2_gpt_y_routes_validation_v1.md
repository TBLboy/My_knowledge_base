## 1. C8-1：signed-response 谱界（必要性门）

局部线性响应 Jacobian `J = ∂d/∂u`（P2 经固定输出反射 `S0 = diag(-1,1)`），k=300 近邻最小二乘，n_query=900。

| 平台 | μ (q05 λmin) | L (q95 λmax) | κ (q) | μ (median) | L (median) | κ (median) | 局部强单调占比 |
|---|---|---|---|---|---|---|---|
| P1 | −7.27（<0） | 585.2 | — | 25.21 | 228.6 | **9.07** | **90.6%** |
| P2 (S0 J) | 5.5e-4 | 6.5e-3 | **11.84** | 9.7e-4 | 1.61e-3 | 1.67 | **99.67%** |
| P2 (未整流 J) | −5.7e-3 | 5.7e-3 | — | −1.29e-3 | 1.29e-3 | — | 0% |

**读数**：
- P2 固定输出反射后 **99.67% 局部强单调**（与第六轮 T6-0 的 99.67% 一致）；P1 **90.6%**。
- 谱展宽真实存在：P2 若用 [q05,q95] 则 κ=**11.8**；若用中位区间则 κ=**1.67**（同一平台两种读法差 7×，说明下尾很重）。
- **必要性门**：κ 不接近 1 → 理论上 Chebyshev 有空间（理论：κ=11.8 时 6 步最坏收缩 const 0.362 vs Cheb 0.055，6.6×）。**故必须做 replay**。

## 2. C8-2/C8-3：离线 exact-J replay（决定性否决 Y3）

在 test/train 轨迹上取长度 N 的窗口，逐样本用局部 Jacobian `J_k` 模拟闭环响应误差递推
`e_{k+1} = (I − α_k J_k) e_k`，比较：
- **const**：`α = 2/(L+μ)`（只用全局谱界的最优常数增益）；
- **Cheb**：同区间 Chebyshev 增益序列；
- **oracle-const**：逐窗用该窗 `λmin,λmax` 的最优常数增益（信息上界）。

| 平台 | 区间 | κ | N | const med | **Cheb med** | Cheb 更优占比 | 越界步占比 |
|---|---|---|---|---|---|---|---|
| P2 | wide | 12.18 | 4/6/8 | 0.145 / 0.047 / 0.0146 | 0.230 / 0.142 / 0.0504 | 36.5 / 23.5 / 24.3 % | ~10% |
| P2 | tight | 1.69 | 4/6/8 | 0.082 / 0.032 / 0.0101 | 0.114 / 0.0436 / 0.0148 | 37.5 / 36.5 / 37.0 % | ~89% |
| P1 | wide | 114.8 | 4/6/8 | 0.274 / 0.144 / 0.077 | 1.163 / 1.656 / 2.326 | 6.5 / 2.3 / 1.3 % | ~9% |
| P1 | tight | 8.21 | 4/6/8 | 0.343 / 0.269 / 0.197 | 1.008 / 1.366 / 1.691 | 19.3 / 16.8 / 15.3 % | ~88% |

**读数**：
1. **Chebyshev 在所有 N（4/6/8）、两种区间、两个平台上，都从未胜出**（Cheb 更优占比恒 <50%，P1 低至 1.3%）。
2. 原因是结构性的：wide 区间按构造就排除 ~10% 样本（q05/q95），tight 区间排除 ~89%；Chebyshev 多项式在区间外增长极快，而其增益上限 `1/μ` 远大于常数增益 `2/(L+μ)`，故越界步被放大。
3. **逐窗 oracle 常数增益**相对全局常数只快 ~1.25–2×（如 P2 wide N6：0.038 vs 0.047）→ **即使允许任意谱信息，收益上界也很小**。
4. 物理前提"响应算子在一个 N 步窗内冻结"在真实数据上不成立（J 随 context 显著时变）。

**Y3 判定：KILLED（机制性 + 实验性双重否决）。** 触发 GPT 自设 cheap-test kill 条件第 2、3 条。

## 3. Y1–Y6 逐条判定

| 路线 | 核心 | 判定 | 依据 |
|---|---|---|---|
| **Y1 RDIC** | 响应对偶坐标 + 积分 | **不通过（弱）** | 等价于"响应空间 PI + 逆几何"；Bregman/mirror-descent 属经典（CDC2026 已有 Bregman tracking）。novelty 仅剩"物理响应坐标"解释性论证。积分抗偏置对任意 PI 均成立，不构成控制器创新。 |
| **Y2 PCMSF** | 模型先验 + 在线 secant 校正逆 | **不通过（占位）** | `arXiv:2606.26188`（连续体臂，Broyden secant + Kalman 在线 Jacobian 补偿）与经典 resolved-rate/Broyden Jacobian 伺服同构。 |
| **Y3 CMRC/SARC** | Chebyshev 最小极大瞬态多项式 | **KILLED** | 见 §2 replay。 |
| **Y4 MPDRC** | 极小多项式有限步 | **KILLED（Y3 子集）** | 同为固定算子多项式控制，随 Y3 一并失效；且死拍控制经典。 |
| **Y5 SARF** | Anderson 多误差加速 | **不通过（门禁排除）** | Anderson acceleration 成熟且已用于最优控制数值（2604.14803 等）；属"数值加速移植"，门禁 v0.3 排除。 |
| **Y6 IPRC** | proximal/resolvent 隐式 | **不通过（classic）** | GPT 自列 fallback；proximal point / resolvent 为成熟单调算子方法。 |

## 5. 对第九轮的新硬约束（供交接）

本轮产生的、GPT 第八轮尚不知道的证据：

1. **响应谱是"bulk 强单调 + 重尾 + 时变"**：P2 中位 κ≈1.7，尾部 κ≈12；P1 中位 κ≈9，9.4% 邻域 λmin<0。**不存在一个紧而准的固定谱区间**。
2. **任何固定小区间都排除大量样本**（tight 区间排除 ~89%），**开环谱加速（Chebyshev/多项式）结构性失败**。
3. **逐窗最优常数增益相对全局常数只快 1.25–2×** → 控制器性能对谱信息的敏感度低，**单纯"更聪明的增益"空间很小**。
4. **在线 Jacobian/secant 自适应已被占用**（2606.26188）→ Y2 类路线关闭。
5. 因此：**在现有数据上，"迭代逆/加速"这一整族控制器设计轴已被封闭**。

**第九轮若仍走现有数据**，必须换到"迭代逆/加速"之外的控制机制（例如：利用响应算子的多步时间记忆结构、或显式的模型误差/不确定性界定而非在线辨识）。若无法指出该轴，则应转向 **新增观测（C1/C2/C3）** 或 **A′ 表征/证伪论文**。
