## 1. 控制响应算子（两平台统一视角）

对离散控制步定义一步响应 `d_k = x_{k+1} − x_k`，控制响应算子 `d = G_c(u)`（c 为可观测 context）。

| 平台 | 状态 | 输入 | 采样 | 观测完备性 |
|---|---|---|---|---|
| P1 | `x=[q,dq]∈R⁶` | 关节力矩 `u∈R³` | 250 Hz | 全观测 EL |
| P2 | 平面点 `x∈R²` | 命令 `(dx,dy)∈R²` | 0.2 s | 缺张力/绳长/速度/模态 |

## 2. 单调性与符号结构

- **P1**：`sym(∂d/∂u)` 局部正定率 **90.6%**；corr(u,d) 对角 [0.576, 0.405, 0.214]；条件数中位 5.4。→ 大范围强单调。
- **P2**：`sym(∂d/∂u)` 本地正定率 **0.286%**（几乎处处不定）；经**固定常数输出反射** `S0 = diag(−1,1)` 后 `sym(S0 J)` 正定率 **99.67%**；det(S0 J)<0 占 99.78%；特征架 circ std 3.16°。
- **可积性**：P2 势梯度模型 val RMSE 0.0188（无约束向量 0.0196）→ 近可积。存在响应势 `Φ_c` 使 `S0 d ≈ ∇_u Φ_c(u)`。

**读数**：两平台的响应算子本质是"**（差一个固定输出取向即可）强单调**"。该结构是经典单调算子/逆控制理论的标准适用域。

## 3. 谱结构（κ 与重尾）

局部 `sym(S0 J)` 特征值统计：

| 平台 | μ(q05 λmin) | L(q95 λmax) | κ(q) | μ(中位) | L(中位) | κ(中位) | 越界比例 |
|---|---|---|---|---|---|---|---|
| P1 | 5.25 | 599.8 | 114.8 | 28.3 | 232.6 | 8.21 | ~9% |
| P2 (S0 J) | 5.4e-4 | 6.6e-3 | 12.2 | 9.4e-4 | 1.59e-3 | 1.69 | ~89%(tight) / 10%(wide) |

**读数**：
- 谱展宽**真实存在但重尾**：中位 κ 与分位 κ 相差数倍。
- **不存在一个既紧又准的固定谱区间**：收紧区间 → 大量样本越界（tight 区间越界 ~89%）。

## 4. 时间记忆结构

- 一步残差协方差有效秩：90% = **2**，99% = **4**（P2，n=26640）。
- 残差块 Hankel 秩：90% = **78** / 99% = **97**（满秩 100）→ **无低阶动态实现**。
- 多步残差：2 步/1 步比中位 2.21、q95 5.36 → 一步预测残差显著增长，响应有记忆但非低阶。

**读数**：响应算子不是有限阶线性动力系统；"低秩 obstruction"存在但无低维动态可实现。

## 5. 负结果：经典逆/加速控制器为何在真实响应上失效

离线 exact-J replay（P1/P2，N=4/6/8，wide/tight 两区间）：

- **Chebyshev（最小极大多项式）增益从未优于最优常数增益**（更优占比 1.3%–37.5%）。
- 原因（结构性）：任一固定区间都排除大量样本（wide 按构造排除 ~10%，tight ~89%）；Chebyshev 增益上限 `1/μ` 远大于常数增益 `2/(L+μ)`，**带外步被放大**。
- 逐窗 oracle 最优常数增益相对全局常数仅快 **1.25–2×** → 谱信息收益上界很小。
- "响应算子在一个 N 步窗内冻结"的假设在真实数据上**不成立**（J 随 context 时变）。
- 在线 Jacobian/secant 自适应（可修复时变）**已被占位**：`arXiv:2606.26188`（连续体臂，Broyden secant + Kalman 在线 Jacobian 补偿）+ 经典 resolved-rate Broyden 伺服。

## 6. 对新控制器的含义（若走 C 或新机制）

一个在现有观测下真正新颖的控制器，必须**同时跨过**以下三重障碍（否则落入已占位/已失效族）：

1. **时变 + 重尾**：不能假设固定谱区间；
2. **带外放大**：任何开环调度的增益序列会在越界样本上失稳；
3. **在线辨识被占位**：不能靠"在线估计 J 并求逆"取胜。

可行方向（待 GPT 第九轮给出机制级方案）：
- 利用**多步时间记忆**（§4）的控制器（须与已占位残差结构划界）；
- 用**已知不确定性界定**（κ、越界比例、整流缺陷）构造鲁棒控制律，而非在线辨识；
- 利用 P1 vs P2 的**结构差异**（强单调 vs 需固定反射）。
- 或 **C：新增观测**（中段 2D 标记 / 差动绳长 / 差动张力）以改变响应算子的可观测结构本身。
