## 3. 第四轮验证结果（本轮核心）

### 3.1 Q0 成立，但非贡献
固定 lifting + 无约束仿射 LS 下，**线性 prefeedback 不改变最优 closure residual**（数值验证偏差 **精确 0.0**）。这是正确的线性代数恒等式（regressor row space 不变），但**教科书级**，不构成新定理。

### 3.2 Q1/Q6 在 P2 上被杀死（关键）
在**冻结的部署 lifting** 下（代码冻结下唯一可行设置），重拟合 `z+ = A z + B(u−α(z))`：

| α | val RMSE（归一化） | 残差秩 90/99 |
|---|---|---|
| 无 | 0.008029 | 2/4 |
| 线性 Kz | 0.008031 | 2/4 |
| 二次 | 0.008005 | 2/4 |
| MLP（秩 m=2） | 0.008030 | 2/4 |
| **全秩非线性漂移（秩 n=10）** | **0.008009** | 2/4 |

**连全秩（rank-10）非线性增广也只降 0.25%，且残差有效秩完全不变。** 反馈无法重塑 P2 的 obstruction。Q1 的唯一退路是 lifting+feedback **联合重训**——那正是被拒绝的原路线，且被 **Fan et al., arXiv:2401.08153**（smooth prefeedback + generalized feedback linearizability）占位。

P1 上非线性 prefeedback 降 31%，但残差**仍 100% 在 im(B)、秩仍 3** → 只是学回 input-channel 重力非线性（标准辨识）。

### 3.3 Q2 被杀死
P2 残差块 Hankel（L=10）秩 **90%=78 / 99%=97（满 100）**，奇异值谱平坦。→ **无低阶动态实现**。第三轮 D7 的“低秩 obstruction”只是**瞬时协方差**结构，不是低阶动态。最小 obstruction order n_η ≈ n，不是 2–4。

### 3.4 Q3 弱/失败
P2 r=4：优化 mode placement 后 **ρ_E=0.9675、闭环 ρ=1.0** → 无法在保持稳定下让 obstruction 快衰减；且属经典 eigenstructure assignment。

### 3.5 Q4/Q5
- Q4：Q0 给 J₁=J₀；但 Q1 杀死使 J₂<J₁ 在 P2 不成立 → 层级坍缩。
- Q5：obstruction 子空间**可复现**（前 2–3 维主角度 <1°，T4-4 支持），但 T4-3（动态全阶）+ T4-2（不可反馈重塑）否决“低维非线性核”的紧凑性。

### 3.6 新增 prior-art 边界
- **Fan, Yi, Rye, Shi, Manchester, arXiv:2401.08153**（Automatica）：明确研究 **smooth prefeedback + generalized feedback linearizability** 的 Koopman embedding。**任何“prefeedback 让系统 exact Koopman-线性”不再算新。**（你已在 §7/§25 自认。）
- **Strässer et al., arXiv:2509.02839**（Annual Reviews in Control 2026）：Koopman 控制"误差界 → 闭环保证"系统综述。压缩 Q1 Theorem C / Q6 闭环界。
- **arXiv:2510.05359**（Koopman Control Factorization：控制器–模型联合凸设计）、**2606.10344**（RKHS 下精确双线性）、**2201.05098**（Neural Koopman Lyapunov Control）。
