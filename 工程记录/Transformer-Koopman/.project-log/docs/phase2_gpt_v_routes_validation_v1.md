## 1. 实验 T5-A/B/C/E（数据即证据）

脚本：`V_P12.py`、`V_P12b.py`。d 定义：P1 `d=(dq_{k+1}−dq_k)/Δt`；P2 `d=x_{k+1}−x_k`。局部回归：kNN 邻域内拟合 `d ≈ a + J u`，报告对称部特征值。

| 指标 | **P1**（n=74,640） | **P2**（n=20,720） |
|---|---|---|
| corr(u,d) 对角 | +0.576 / +0.405 / +0.214 | **−0.611 / +0.620** |
| corr 非对角 | ≤0.083 | ≤0.041 |
| 局部 λ_min(sym J) 中位 | **+25.82** | **−0.001228** |
| 局部 λ_max(sym J) 中位 | +225.43 | +0.001260 |
| **正定比例（两个特征值都>0）** | **92.57%** | **0.29%** |
| **负定比例** | 0.0% | 0.0% |
| **不定比例（鞍点）** | 7.43% | **99.71%** |
| curl 比 ‖J−Jᵀ‖/‖J+Jᵀ‖（全局/局部中位） | 0.050 / 0.205 | 0.005 / 0.054 |
| 局部 σ_min(J) 中位 | 32.0 | 9.6e-4（>0，局部可逆） |
| 条件歧义（近邻 d 扩散 / 基线） | 0.342 | 0.214 |

### 判读
1. **P1 强单调成立**：92.6% 邻域对称部正定，λ_min 中位 +25.8；corr 对角正。与 `∂(M^{-1}(τ−b))/∂τ = M^{-1}≻0` 一致。→ **V1/V2 在 P1 有真实物理锚点**（GPT 的物理推导正确）。
2. **P2 既不单调也不反单调**：局部对称部 **99.7% 不定**（λ_min<0<λ_max），PD 0.29%、ND **0%**。→ **符号翻转也无法挽救**（diag(−1,1) 共轭保持不定）。→ **V1（强单调）死**；**V2（凸势要求梯度场=对称半正定 Hessian）死**（这里是负曲率鞍）；**V3（单调算子需对称部半正定）死**。
3. **P2 响应近乎确定且近乎对称**：curl 仅 0.005–0.054（近可积）、条件歧义 0.214（低，非主导）。→ 它是一个**近似梯度场，但势函数非凸（鞍）**。
4. **P2 局部可逆**：σ_min 中位 9.6e-4 > 0（局部单射）。→ “响应逆控制”在 P2 可行，但**只能作为一般局部可逆映射**，而这一点 GPT 自己在 §48 已判为不新（soft-robot inverse dynamics）。

## 3. 关键科学发现（可留作证据）

1. **P1 控制响应强单调**：局部 Jacobian 对称部 92.6% 正定，与 EL 惯性矩阵正定一致——**V1/V2 的物理锚点在 rigid 平台上真实成立**。
2. **P2 控制响应是近对称鞍点**：局部对称部 99.7% 不定，curl 低、条件歧义低——**既非单调也非凸**，且**不是**部分可观测噪声导致（歧义仅 0.21）。
3. **双平台对比**：`dim u = dim d` 的方形响应在 P1 上可逆且单调，在 P2 上可逆但**鞍形**——**不能用同一条“可逆单调响应几何”统一**。

## 4. 元结论（跨五轮）

R(18)/N(6)/M(12)/Q(7)/V(6) 之后，在门禁 v0.2 下**仍无候选存活**。五轮复现的模式：

1. P2 的困难**不是**“模型不够好”：它的响应**已近乎确定（歧义 0.21）、近乎可积（curl 0.05）、局部可逆（σ_min>0）**，但**结构（鞍）不满足任何已知可被“漂亮定理”利用的性质**（单调/凸/闭合）。
2. P1 反而**处处满足**经典结构（单调、im(B)）。
3. 因此“用同一机制统一两平台”这一目标，在现有可观测量下**屡屡失败**。
