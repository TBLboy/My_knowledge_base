## 1. 你的推断与本轮检验

- 第十轮：观测空间代理（`d = J(φ)·u`，低秩算子调制 vs 加性）→ 得出"modulation ≫ additive"。
- 第十一轮：在**加性基座**上做 A/B/AB 消融 → B-only ≫ A-only（H20 −67% vs −42%），matched-state 3.24× → 你据此把路线 A 收窄为 **A+（RSHC-TK）**，并建议 **B(c) 为 locus**（可选 AB）。
- 本轮：把同一问题放到**真实 latent 管线**上重做。**结果与你的推断相反。**

## 2. 方法（真实管线）

- 模型：`PatchTSTEncoder(x_history[B,P,n]) → z=[x_t;h]`（d=10），`z' = A z + B u`，`decoder=前2维`（仓库现有实现）；**新增** context encoder（`[x_history; u_history] → c∈R^16`）+ 低秩调制：
  - `A(c)=A0+Ua·diag(ga(c))·Vaᵀ`（`Ua,Va∈R^{10×3}`）
  - `B(c)=B0+Ub·diag(gb(c))·Vbᵀ`（`Ub∈R^{10×3}`, `Vb∈R^{2×3}`）
  - 模式 fixed / A / B / AB
- 训练：先端到端训 fixed（100 ep, lr1e-3, bs256），A/B/AB 从 fixed 继承权重 + 调制零初始化后微调（lr5e-4, 100 ep）。**四模式同流程**，seed 0/1 各一遍。
- 评估：自由滚动 rollout（每步重编码 + 重算 c），H=1/5/10/20，val/test，归一化空间 RMSE。
- 证伪：modOFF（关闭 ΔA/ΔB）、uhZERO（上下文输入历史置零）。
- 锚点：部署 EDMD 模型同协议 rollout。

## 4. 解读

1. **locus = A**：A-only 改善 73.7%/74.3%（两 seed），远超阈值；B-only 几乎无增益、长时域甚至更差；AB ≈ A-only。
2. **为什么你的推断不迁移**：观测空间代理 `d = J(φ)·u` **结构上只能调制输入通道**，因此它天然只能"看到"B 效应，无法表达状态转移调制 → 在代理上"B 胜出"是**代理结构的人为结果**。真实 latent 的 `A` 作用在 `z=[x;h]`，`h` 编码历史，`A(c)` 才能表达"历史依赖的潜在动力学"——这正是 RSHC-TK 的表达力来源。
3. **证伪通过**：modOFF 崩溃 → 增益来自调制本身；uhZERO 崩溃 → 确实依赖输入历史。

## 5. 决定

- **A+ 采用 A-only 低秩上下文调制**（`A(c)=A0+Ua·diag(ga(c))·Vaᵀ`，r=3），`B=B0` 固定。放弃 B-only 与 AB。
