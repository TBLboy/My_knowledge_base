# 阶段② delta 2（保无源/保正定 lifting）可证伪最小版本 v0.1

> 日期：2026-09-29  
> 用户选择：先构造 delta 2 的可证伪最小版本（保无源 / 保正定 lifting）。  
> 目标：判定“P1 数据能否支持一个非空泛的无源/passivity 证书”，从而支撑保无源 lifting + 无源控制器路线。

## 1. 最小可证伪命题

若 delta 2 成立，必须同时满足：

1. 能从 P1 数据辨识出**正定惯量** `M(q) ≻ 0`；
2. EL 结构模型残差足够小，使**能量平衡/无源性裕度非空泛**（即残差不吞掉耗散项）；
3. 由此可构造一个“保无源 lifting + 无源控制器”的闭环稳定性论证。

**Falsification 条件：** 若无法得到 PD 惯量，或 EL 残差大到使无源裕度退化为不确定扰动界，则 delta 2 在当前数据下不成立。

## 2. 实验与结果

### 2.1 采样与数据

- 采样率 **250 Hz**（`dt=0.004 s`）；轨迹时长约 19.92 s。
- P1：train 15 条、val 4 条；`x=(q,q̇)` 全状态；`u` 力矩。

### 2.2 常量惯量 EL 模型（最小版）

模型：`τ ≈ M q̈ + C q̇ + g(q)`，`M` 常量对称，`C` 常量，`g(q)` 为 `[1,q,sin q,cos q]` 基。

结果：

| 项 | 值 |
|---|---|
| val RMSE / 关节 | 0.4805 / 0.5631 / 0.3323 |
| 力矩标准差 / 关节 | 0.9186 / 0.9186 / 0.5461 |
| 恢复的 `M` 特征值 | 0.000755 / 0.001469 / 0.002161 |
| `M` 正定 | **是** |
| `M` 条件数 | 2.86 |

### 2.3 富 EL 模型（含 `M(q)`、科氏/离心、库仑摩擦，75 块）

结果：

| 项 | 值 |
|---|---|
| train RMSE 整体 | 0.3556 |
| val RMSE / 关节 | 0.3442 / 0.4214 / 0.2598 |
| val RMSE / std（相对残差） | 0.3747 / 0.4588 / 0.4757 |
| 解释方差 R² 近似 | 0.860 / 0.790 / 0.774 |

即：即使使用比标准 Koopman 更强的物理结构，仍有 **约 37%–48% 相对力矩标准差**的残差。

## 3. 判定

- **正向（弱支持）：** 存在正定惯量 `M≻0`，与力矩驱动 EL 结构一致；这排除了“输入语义不支持 EL 结构”的担忧。
- **负向（未通过）：** EL 残差相对信号偏大（0.37–0.48），且残差来源混合了未建模动力学（摩擦/关节柔性/电流-力矩非线性）与速度量化噪声（250 Hz）。**无法从中分离出一个非空泛的无源性裕度。**
- **结论：** delta 2 的可证伪最小版本**未通过**。不是被证伪为数学错误，而是**当前数据 + 当前建模无法给出可用的 passivity margin**。

## 4. delta 2 若要复活，需要满足

1. 用更好的状态估计/噪声模型把测量噪声从动力学残差中分离，证明残差主要是噪声；或
2. 用更强的结构辨识（电流-力矩映射、关节摩擦模型、柔性）把 EL 残差显著压低；并使
3. 得到的无源裕度在数值上显著大于残差界，且该裕度对应一个**新的闭环定理**（不是标准无源控制换名）。

否则 delta 2 在现有数据下不成立。
