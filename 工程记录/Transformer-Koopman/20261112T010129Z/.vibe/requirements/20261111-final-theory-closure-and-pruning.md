## 4. 已确认的业务/研究规则及验收标准

### Rule 1：研究任务不变

研究对象是动态参考轨迹跟踪，不得改写为静态平衡点或逐时刻移动稳态调节。

**验收：**摘要、引言、问题定义、控制器、定理和结论的对象都是随时间变化的物理参考轨迹。

### Rule 2：模型身份不变

实际模型是第三章历史条件化 Transformer–Koopman；z 是升维/冻结 QP 坐标，a、v 是历史调度记忆，q 是完整递归/分析包装，不要求跟踪 qᵣ。

**验收：**任何冻结 QP 简化都说明“冻结后缓存不再反馈进入 z 预测”，不把完整模型改写成普通固定 z⁺ = Az + Bu。

### Rule 3：跟踪目标不变

跟踪权重固定为 Q = diag(Qx, 0)，Qx ≻ 0；直接惩罚物理测量分量，Transformer 特征参与预测但不被默认强制跟踪。

**验收：**不存在未经批准的全潜变量跟踪、完整 q 参考或参考输入前置接口。

### Rule 4：控制器必须真实

控制器保留一次完整标称展开、系数冻结、LTV-QP、输入约束、首输入实施和滚动重算；输入正则和终端机制可由最终证明选择，但不能为了证明而悄悄改变控制任务。

**验收：**主定理中的控制律与算法逐项一致；冻结误差、重编码残差、输入约束和求解器行为均有对应位置。

### Rule 5：正文只保留一条主证明链

最终正文应有一个主定理，必要时配套最小数量的定义、假设、引理和一个直接推论。其他路线归档为研究备选，不与主定理并列竞争。

**验收：**删除任一探索性分支后，正文主线仍可从模型、控制器走到主定理；读者不需要阅读 Stage 1–7 才能理解论文。

### Rule 6：结论强度服从证据

可以使用条件性实用跟踪、有界性、窗口型指数界等准确表述；不得从 QP 严格凸、有限时域代价界、开环收缩或单点 Jacobian 直接宣称一般零误差指数稳定。

**验收：**每个“稳定/指数/精确/有界”词都能在主证明中找到对应假设和递推；实际训练模型未认证时不写成已满足条件。

### Rule 7：论文要剪枝

优先保留能支撑主结论、解释模型与控制器关系、或构成论文核心贡献的理论；细枝末节、重复界、冗余路线、仅用于探索的例子和无法服务主线的特例从正文删除。

**验收：**正文理论段落均能回答“它为主定理提供了什么”；不能回答的内容移至内部材料或删除。
