**审查对象：** `Main9_Stage3_IEEE_Polished.tex`，以第二、三章和第四章的冻结预测式为事实依据。  
**研究约束：** Baseline v2.1；动态参考轨迹跟踪；真实模型必须是第三章的历史调度 Transformer–Koopman；升维跟踪代价只对前 `n` 个测量状态分量赋非零权重。

## 一、执行结论（先给技术判断）

1. **当前第三章的 `z_k` 不能在现有定义下被认定为单独闭合的一步预测状态。** 现有转移矩阵 `A` 通过 `C_φ(X_k,v_k)` 依赖最近的测量历史和输入历史。由于 `z_k=G_θ(X_k)` 并未包含独立的输入历史 `v_k`，论文也未证明历史可由 `z_k` 唯一恢复，故不能直接写出一般成立的 `z_{k+1}=\Phi(z_k,u_k)` 并保留现有历史调度含义。
2. **递归历史记忆需要保留，但未必需要继续作为独立的“增广 Koopman 状态”来突出。** `a_k,v_k` 的首要作用是保持每一步未来调度所需的历史可更新；它们是确定性移位缓存，不是额外学习出的 Koopman 特征。`q_k=(z_k,a_k,v_k)` 是把预测器写成自治一步映射的一个方便实现，**不是动态参考跟踪对象**。
3. **在当前的“单次冻结”结构下，可以严格将冻结 LTV-QP 的预测状态缩减为 `z_{i|k}`，无需让缓存成为 QP 中的状态变量。** 保留一次完整名义递推所需的 `q`/缓存；冻结得到 `\bar A_i,\bar B_i` 后，QP仅使用 `z_{i+1|k}=\bar A_i z_{i|k}+\bar B_i u_{i|k}`。这与现有冻结增广模型的 `z` 分块逐步一致（前提是目标/约束仅依赖 `z`、优化输入及其增量，且移除旧稳态护栏等专用项）。
4. **优先建议的方案：区分三种对象。** `z` 是学习得到的升维预测/跟踪坐标；`(a,v)` 是用于生成调度系数的预测器记忆；`q=(z,a,v)` 可作为全模型递归及理论分析的紧凑记号，但不必作为 MPC 的跟踪坐标，也不必被显式搬进冻结 QP。是否在正式第三章保留 `q` 这一符号，还要结合新的定理写法审定；目前不建议直接删掉其数学作用。
5. **跟踪权重已锁定：** `Q=diag(Q_x,0)`，`Q_x` 对前 `n` 维物理测量状态赋权，Transformer 特征的直接跟踪权重为零。控制正则项（输入幅值、输入增量等）仍开放。

## 三、为什么 `z` 单独不一定形成闭合的转移映射？

把第三章实际的第一分块展开：

\[
 z_{k+1}
 =A\!\left(C_\phi\!\left(\operatorname{col}(a_k,C_xz_k),v_k\right)\right)z_k
 +B(C_xz_k)u_k.
\]

如果只给定 `(z_k,u_k)`，右侧一般还需要 `(a_k,v_k)`。论文没有定义 `a_k=a(z_k)` 或 `v_k=v(z_k)`，也没有证明一个可逆/充分统计量条件。因此：

- **已能严格确定：**当前数学定义**不足以推出**存在仅依赖 `(z,u)` 的同一个递归函数 `\Phi(z,u)`，且保持原调度结构。
- **不能过度断言：**并非对任何网络权重绝对不可能。例如退化为常值调度、或者某种经证明的历史充分表征时，可能实现 `z` 闭合；但现稿没有采用这些特例或增加相应假设。
- **关键成本：**只是把 `q` 改称“`z` 加外部记忆”并不会消除计算所需的历史数据维数。可改变论文概念组织方式，却不能无理由宣称真正降低模型阶数。

以目前保留历史条件化低秩 `A` 为前提，**未来历史记忆不能凭空消失**。

## 四、严格推导：冻结 QP 可以只用 `z` 作为预测状态

**第一步：完整模型标称轨迹仍使用全部历史记忆。**

\[
\bar q_{0|k}=q_k^E,\quad
\bar q_{i+1|k}=F(\bar q_{i|k},\bar u_{i|k}),
\]
\[
\bar A_{i|k}=A(c(\bar q_{i|k})),\quad
\bar B_{i|k}=B(C_x\bar z_{i|k}).
\]

**第二步：冻结后仅递推 `z`。**

\[
\boxed{\ z_{0|k}=G_\theta(\mathcal X_k),\qquad
 z_{i+1|k}=\bar A_{i|k}z_{i|k}+\bar B_{i|k}u_{i|k}.\ }
\]

**为什么这不是擅自替换第三章模型？** 现稿冻结增广方程为

\[
 p_{i+1|k}=\begin{bmatrix}
\bar A_{i|k}&0&0\\E_xC_x&S_x&0\\0&0&S_u
\end{bmatrix}p_{i|k}
 +\begin{bmatrix}\bar B_{i|k}\\0\\E_u\end{bmatrix}u_{i|k}.
\]

取这个方程的第一分块，**恰好就是**上述只含 `z` 的冻结方程。由于系数已固定，后两分块不再反馈进入第一分块。对每个候选控制序列 `U`，二者产生**完全相同的**冻结 `z` 预测（可由 `i` 的数学归纳法得证）。

因此，在新 MPC 只对 `z` 误差、`u` 或 `Δu` 等施加代价和约束时，冻结阶段没必要显式优化整套 `q`。这将**优化表述**与**完整模型内存机制**分离，而不是把第三章模型改成常值 Koopman。

**重要限定：**如果以后引入某种直接依赖缓存的状态约束/成本，消元时需要单独证明其等价形式；不能不加条件地省略。

**另外：**当前第三章结构使冻结预测与完整模型对任意首个候选输入具有一致的第一步更新，因为 `c(q_k^E)` 不依赖当前待优化的 `u_k`；从第二步开始，系数冻结才产生候选输入与名义历史不一致的可能。这是后续冻结误差分析可以利用的具体结构事实。

## 五、已固定的动态轨迹跟踪代价

给定编码器所需的完整测量参考历史：

\[
 z_{k+i}^{\rm r}=G_\theta(\mathcal X_{k+i}^{\rm r}),\qquad
 Q=\operatorname{diag}(Q_x,0_{d-n}),\quad Q_x\succ0.
\]

统一用升维坐标写跟踪项：

\[
\boxed{\ J_{\rm tr}(U)=\sum_{i=1}^{N}
 (z_{i|k}-z_{k+i}^{\rm r})^\top
 Q(z_{i|k}-z_{k+i}^{\rm r}).\ }
\]

按照 `z=col(x,ψ)` 的结构，此式**严格等于**

\[
 J_{\rm tr}(U)=\sum_{i=1}^{N}
 (C_xz_{i|k}-x_{k+i}^{\rm r})^\top
 Q_x(C_xz_{i|k}-x_{k+i}^{\rm r}).
\]

这不是改变研究目标：形式上是**升维空间跟踪代价**，实际只评价物理测量状态；Transformer 特征通过预测动力学间接影响物理轨迹。即使 `q` 被保留，代价也不要求一条 `q^{\rm r}`，只需提取 `z`。

**数学后果：**因为 `Q` 是半正定，单靠跟踪成本通常不足以保证输入序列的严格凸性/唯一最优解。若需要严格凸 QP，可以选择 `R\succ0` 的输入幅值成本或 `S\succ0` 的输入增量成本等；这是待设计的控制正则项，不应反过来改变已经确定的 `Q`。

**参考变量一致性提醒：**当前第三章 `G_θ` 接受完整测量窗口 `\mathcal X`，而旧第四章曾使用 `y=C_yx` 的低维输出参考。若研究目标是完整 `x` 轨迹，升维参考的计算直接成立；若只提供机械臂末端任务空间坐标，但编码器输入还包含其他传感量，则必须另外明确测量参考来源，不能把低维 `y^{\rm r}` 直接当作 `\mathcal X^{\rm r}`。

## 六、对第三章命题、训练和第四章的影响

**第三章已验证的结构：**时序 lift、`A(c)`/`B(x)` 低秩修正、基于真实历史的编码初始化、基于预测历史的调度递推，均可保持原有研究意图。

**训练过程：**原多步训练使用 `F` 维护缓存，预测损失基于 `z` 的物理读出及与重新编码特征比较。若只是把缓存与 `z` 在文字上拆分而保留等价的更新式，训练动力学不需实质改变；若真的更改编码器充分性或调度输入，则涉及重新建模与训练方案，不属于本阶段建议。

**原第三章收缩命题：**当前命题的 `\Pi` 建立在 `M_0` 的整个增广维度上。可暂作*预测器结构性质*保留研究，但它不是新动态轨迹 MPC 的闭环保证；后续必须检查其对新控制律的实际价值。若正式移除 `q` 作为数学状态，须重新定义/证明同等性质。

**第四章旧定理：**旧 `u^b,q^b` 名义稳态选择器、首输入护栏和围绕移动稳态点的误差递推均不视为新动态轨迹 MPC 的既定部分。需要重建真正的参考升维代价、冻结 QP、可行性与闭环跟踪定理；不能把旧证明直接移植。

## 七、建议的下一步与建议采纳项

- **核心 Koopman 升维状态：**`z`。

- **在线冻结 LTV-QP：**只用 `z` 与候选输入预测，跟踪 `z^{\rm r}` 且 `Q=diag(Q_x,0)`。

这是一项**有明确代数依据的推荐方案**，尚未获得作者对正式论文结构修改的授权。因此本阶段不重写第三章/第四章。
