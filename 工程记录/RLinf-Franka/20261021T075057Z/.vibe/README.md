# Vibe Coding V2 Project State

This directory is the project state root for the Vibe Coding V2 framework.

- Persistent Tasks: `tasks/<task-id>.json`
- Durable project progress: `progress.md`
- Session recovery: `sessions/<session-id>/current-session.md`

Task files must follow the schema in the framework's `docs/04-DATA-CONTRACTS.md`.
