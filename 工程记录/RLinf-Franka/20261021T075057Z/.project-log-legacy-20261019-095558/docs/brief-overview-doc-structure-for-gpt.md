## 二、项目背景（这是什么、做到哪了）

- **目标**：用 Pico VR 头显遥操作一台 **Franka Research 3 单臂**机械臂，采集人类演示轨迹，
  供后续 VLA 模型做**监督微调（SFT）**、**HG-DAgger 在线干预训练**与**真机 RL 部署**。
- **框架**：RLinf（embodied 版本），源码安装，固定到某个 commit。
- **本机角色**：**只做数据采集**；无 NVIDIA GPU；跑 PREEMPT_RT 实时内核。
- **机械臂驱动**：**不用 ROS**，走 `franky` + `libfranka` + FCI（**笛卡尔阻抗控制**）。
- **相机**：ZED 2i 走 **UVC 裸流**（不用 ZED SDK，因为它需要 NVIDIA GPU），
  通过框架的 **out-of-tree 扩展**机制接入。
- **夹爪**：Robotiq，USB-RS485 + Modbus RTU。
- **VR 侧**：XRoboToolkit（PC Service + 头显 app）+ 自写的 ZMQ 数据发布器。
- **当前状态**：链路全部跑通且有真机验证证据；已有**操作手册**（1755 行）
  与**问题记录**（27 条，按现象分类索引）。

## 三、读者与使用场景

- **读者**：项目所有者本人（有技术背景，但不了解这个项目的内部细节）。
- **使用场景**：
  1. 阶段结束时**快速复盘**、把握全貌；
  2. 之后**改配置 / 排障**时的第一入口；
  3. 换机、或中断很久后**恢复上下文**。
- **明确不需要**：逐函数讲解、代码逐行分析、上游框架的完整文档（那是框架自己的事）。

## 四、约束与已知难点

1. **易过期**：配置数值（安全盒、缩放系数、阻抗参数）会变。
   文档必须区分「**稳定结构**」与「**会变的数值**」，或者给出"去哪查当前值"的指引。
2. **事实必须可追溯**：项目里明确区分「实测 / 读代码 / 记录 / 推断」四种来源，
   文档**不能把推断写成事实**。
3. **上游代码 vs 自有代码**：项目里大部分代码是**上游框架的**，只有少数是自己写的。
   文档必须让读者分清"**哪些是我需要维护的、哪些是上游的不能动**"。
4. **已有材料很多**：已有操作手册（操作步骤 + 排障）和项目记忆库（决策/证据记录）。
   复盘文档**不应重复它们**，而应**分层引用**。
5. **数据流是核心难点**：项目横跨「头显 → 无线网络 → PC 前置服务 → ZMQ →
   框架遥操作层 → 环境层 → 驱动层 → 机械臂」多个环节，读者最容易在这里迷失。
6. **多个独立"限速/权限"层叠**：同一个"速度"被 3~4 个不同层各自限制，
   读者很难知道"要调快该改哪一个"。

各章要点：

- **1**：一段话 + 一张"维度-内容"表（机器人/设备/框架/相机/夹爪/输出）+ 明确的项目边界（不做什么）。
- **2**：一张 ASCII 数据流图，7 个编号环节；末尾列"三条必须按顺序的铁律"。
- **3**：目录树 + 标注"谁拥有"（我们写的 / 我们新增到上游的 / 上游源码别动）。
- **4**：两张表 —— ① 我们写的文件（含行数与职责）；② 上游参与链路的模块（含行数与在链路里的职责）。
- **5**：主配置文件逐段解释（`cluster` / `runner` / `env.eval` / `pico` / `override_cfg` / `data_collection`），

- **6**：把数据流拆成 6 个阶段逐一说明；末尾讲落盘的两条独立路径。
- **7**：回答"用的是 SDK 吗、IK 在哪"；讲笛卡尔阻抗的 `刚度 × error_clip = 最大作用量`；
  最后用一张表讲清**三层限速**（手柄缩放 / 每步上限 / 驱动层限速）。
- **8**：安全盒的"位置盒（绝对）+ 姿态窗口（必须居中）"；一个真实踩过的坑；为什么某类不一致要**阻断启动**。
- **9**：产物目录树 + `.pkl` 与 `demos/*.pt` 的字段清单（实测）+ 一张"数据可用性结论"表。
- **10**：一键脚本 7 阶段表 + 手动等价 + 四条铁律。
- **11**：决策编号 → 一句话理由（表格）。
- **12**：缺陷表 + 待办表 + 证据状态。
- **13**：术语表（FR3/FCI/franky/libfranka/笛卡尔阻抗/error_clip/UVC/ZMQ IPC/遥操作介入…）。
- **14**：**每条重要结论 → 来源与证据**的对照表（实测/读代码/记录/推断）。
