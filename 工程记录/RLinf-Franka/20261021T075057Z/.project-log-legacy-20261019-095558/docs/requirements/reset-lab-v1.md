# 独立 Reset 实验工具：已确认业务范围

2026-10-18；来源：操作者逐项确认。当前只做澄清与记录，不实施、不操作硬件。

## 目标与边界

在根目录“杂项”下建立实验区，用预采集TCP点位复现整臂Reset移动抖动。实验不抖仅为进入遥操作验证的条件，不等于根因解决。撤回J7突出假设。

## 已确认规则及验收

1. 两个工具：只读点位采集器和多点Reset执行器。给定采集文件，执行器按原顺序使用全部点位，不固定为3点。
2. 操作者自行进入拖动模式；回车记录实测TCP位置/姿态及七关节q，q仅供诊断，不作为Reset关节目标；输入q并回车结束保存，点位顺序标记A/B/C等。读取失败必须报错，不能通过启动控制器、恢复错误、改参数或切换模式来读取。
3. 执行流程当前位置→A→B→…→最后点→A，然后停止控制器、释放连接、退出。中间点Reset返回后停留2秒；最后一点不额外停留直接返A，最终A不再循环。
4. 异常或人工中止时尝试停止并退出，不跳点、不自动返A。记录停止结果；进程退出不等于物理停止已确认。
5. 支持启动归位与采集期间Reset两种模式，默认后者，一次运行不混用。直接从当前位置前往A，不先经过正式配置旧reset点。
6. 启动模式保留初始化参数及插值方式；episode模式先应用实验运行时参数，复刻原Reset判断及重试。新建控制器不具备此前遥操作tracker历史，必须标注此差别。
7. 默认保留原位置判定（不判断姿态）并记录跳过原因；可选强制插值用于纯姿态点位，须标记其偏离原逻辑。Reset调用返回不代表实测姿态到位。
8. 配置、必要资源、Reset/控制代码全部克隆到独立实验区，记录来源版本；独立Python环境和Franky构建，不覆盖正式.venv或正式代码。克隆时重新核对磁盘，当前恢复配置记录为52cdf9a。初版通过离线对照验证等价再试验，不静默修正原算法。
9. 用户允许后续实验配置/算法均可调整；初版不自动改变保护。涉及碰撞、关节限位、力矩变化率等需逐项确认值和影响，不把概括授权解释成任意放宽；Desk不自动修改。
10. 每次保存代码版本、配置、点位文件身份、目标及下发时间、实测TCP/q/dq、可获取状态/错误/到位偏差。记录不得阻塞实时控制；高频力矩作为后续扩展，不伪造不可获得信号。
11. 实验有效后仅经用户确认才向正式遥操作迁移，不自动同步。
