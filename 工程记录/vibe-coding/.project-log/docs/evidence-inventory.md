repository itself to the parent work folder, so many recorded `covers.files`
paths (e.g. `runtime/scripts/...` instead of `vibe-coding/runtime/scripts/...`)
no longer resolve. A one-off Windows CRLF checkout additionally invalidated a
batch of records whose covered bytes were otherwise unchanged.

on: history is never rewritten and freshness is never fabricated. Only rebind
a record when its covered artifact is provably unchanged.
