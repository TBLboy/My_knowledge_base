什么是一个shard：
数据在训练的时候分为物理存储方式和数据送入方式。这个shard就是训练前，本地数据的一个物理存储的方式
每一条数据可以称为一个eposide，每个eposide包含了多个时间步。首先需要采用滑动窗口的方式从eposide里生成一个一个sample（一般有两个窗口，从当前时刻开始往前的state窗口，以及从当前时刻开始往后的action标签窗口）
然后把每个eposide的样本取出来打乱，放入一个一个容器，每一个样本都是（eposide编号，样本）
然后实际训练的时候会先把一个shard内的数据放入内存，然后每次从里边拿一个batech的数据送入GPU，这样不断循环，用完这个shard之后就再换一个shard
shard：磁盘/内存侧的打包单位，偏工程效率
batch：一次 `forward` 塞进 GPU 的样本数，偏优化


DiT的flow matching核心公式：
noise ~ N(0, I)
t ~ Beta(...)          # 0~1 之间的时间
noisy = (1-t) * noise + t * actions
velocity = actions - noise
# 网络预测 pred ≈ velocity
loss = MSE(pred, velocity) * action_mask

flow matching是训练方法，训练出来的模型叫做DIT
DIT可以学习到同一个动作分布下的不同动作，这样在输入相同的情况下，输入不同的纯噪声，最终能输出不同的动作。条件输出速度场，不同的条件下，相同的初始噪声也可能朝着不同的方向移动

同一个任务对应一个条件动作分布（conditional action distribution），这个分布可能包含多个峰值，每个峰值代表一种合理的动作策略。Flow Matching 学习的是一个条件速度场，不同的随机噪声会沿着这个速度场演化，最终落到这个动作分布中的某一个模式，因此生成不同但合理的动作。
