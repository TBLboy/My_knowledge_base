# POMDP（部分可观测马尔可夫决策过程）学习笔记

## 1. POMDP 是什么

POMDP，全称 **Partially Observable Markov Decision Process（部分可观测马尔可夫决策过程）**。

它用来描述这样一类序列决策问题：

> 环境中存在一个真实状态，但智能体无法直接看到完整状态，只能获得不完整、带噪声的观测，并基于当前观测、历史信息或状态估计来选择动作。

POMDP 可以看作 MDP 在现实场景中的扩展。

在 MDP 中，智能体直接知道当前状态：

\[
s_t
\]

而在 POMDP 中，智能体通常只能获得观测：

\[
o_t
\]

因此，POMDP 的核心问题是：

> 当真实状态不可直接获得时，智能体如何根据有限观测做出正确决策？

---

## 2. 为什么需要 POMDP

标准 MDP 默认假设：

> 智能体能够获得当前环境的完整状态。

但现实机器人通常只能通过传感器认识世界，例如：

- RGB 摄像头
- 深度摄像头
- 激光雷达
- IMU
- 力传感器
- 关节编码器

这些传感器提供的都是 Observation，而不是完整 State。

例如机器人抓取杯子时，真实状态可能包含：

- 杯子的三维位置
- 杯子的姿态
- 杯子的速度
- 杯子的质量
- 杯子是否装水
- 物体是否被遮挡
- 桌面摩擦情况
- 周围障碍物位置

但机器人实际可能只看到一张 RGB 图像。

因此：

\[
\text{Observation} \neq \text{State}
\]

这就是 POMDP 出现的根本原因。

---

## 3. State 与 Observation 的区别

### 3.1 State：真实状态

State 表示世界真实、完整的情况。

例如：

\[
s_t =
(
\text{杯子位置},
\text{杯子姿态},
\text{杯子速度},
\text{机械臂状态},
\text{障碍物位置}
)
\]

这些信息客观存在，无论机器人是否能够看到。

### 3.2 Observation：观测

Observation 表示智能体实际测量到的信息。

记作：

\[
o_t
\]

例如：

- 一张 RGB 图像
- 一张深度图
- 一组激光雷达点云
- 关节角度读数
- 力传感器读数

Observation 通常是 State 的一个不完整、带噪声的映射。

可以写成：

\[
o_t \sim O(o_t \mid s_t)
\]

其中 \(O\) 表示观测模型。

### 3.3 核心区别

| 对比项 | State | Observation |
|---|---|---|
| 含义 | 世界真实状态 | 智能体看到的信息 |
| 是否完整 | 理论上完整 | 通常不完整 |
| 是否有噪声 | 真实状态本身无测量噪声 | 通常带噪声 |
| 是否可直接获得 | 现实中通常不能 | 可以通过传感器获得 |
| 例子 | 杯子真实三维坐标 | 摄像头中的杯子图像 |

---

## 4. Observation 为什么不够

单次观测往往不足以确定真实状态。

### 例子一：遮挡

杯子被箱子挡住时，当前图像中看不到杯子。

真实状态：

```text
杯子仍然在箱子后面
```

当前观测：

```text
画面中没有杯子
```

如果只依赖当前观测，机器人可能错误地判断杯子不存在。

### 例子二：速度不可见

单张图像只能显示物体位置，却不一定能判断物体速度。

两个物体当前位置相同：

- 一个正在快速向左运动
- 一个处于静止状态

它们当前图像可能相似，但未来状态完全不同。

### 例子三：隐藏属性

机器人看到一个杯子，但无法仅凭 RGB 图像确定：

- 杯子是否装水
- 杯子是否很重
- 表面是否湿滑
- 杯中液体是否很热

这些都属于真实状态的一部分，但可能无法直接观测。

---

## 5. POMDP 的组成部分

POMDP 通常表示为：

\[
\mathcal{P}
=
(
\mathcal{S},
\mathcal{A},
P,
R,
\Omega,
O,
\gamma
)
\]

其中：

| 符号 | 名称 | 含义 |
|---|---|---|
| \(\mathcal{S}\) | State Space | 真实状态空间 |
| \(\mathcal{A}\) | Action Space | 动作空间 |
| \(P\) | Transition Model | 状态转移模型 |
| \(R\) | Reward Function | 奖励函数 |
| \(\Omega\) | Observation Space | 观测空间 |
| \(O\) | Observation Model | 观测模型 |
| \(\gamma\) | Discount Factor | 折扣因子 |

相比 MDP，POMDP 主要多了：

1. Observation Space
2. Observation Model

---

## 6. Observation Space：观测空间

观测空间记作：

\[
\Omega
\]

它表示智能体所有可能获得的观测。

例如机器人系统中的观测空间可以包括：

- RGB 图像
- 深度图
- 点云
- 关节角度
- 关节速度
- 末端力反馈
- IMU 数据
- 语言指令

如果输入是一张图像，那么观测空间可能是所有可能像素组合构成的高维空间。

---

## 7. Observation Model：观测模型

观测模型记作：

\[
O(o_t \mid s_t)
\]

它表示：

> 当真实状态为 \(s_t\) 时，智能体观测到 \(o_t\) 的概率。

在某些定义中，也会写成：

\[
O(o_t \mid s_t, a_{t-1})
\]

因为智能体执行动作后，新的观测可能同时受状态和之前动作影响。

观测过程可以理解为：

```text
真实 State
    ↓
传感器 / 摄像头
    ↓
Observation
```

例如：

```text
杯子的真实三维位置
    ↓
相机投影、遮挡、光照、噪声
    ↓
二维 RGB 图像
```

同一个真实状态，在不同光照或噪声下可能产生不同观测。

不同真实状态，也可能产生非常相似的观测。

---

## 8. POMDP 中的决策依据

在 MDP 中，策略可以写成：

\[
\pi(a_t \mid s_t)
\]

因为智能体知道真实状态。

在 POMDP 中，智能体不知道 \(s_t\)，因此不能直接使用该形式。

最简单的做法是：

\[
\pi(a_t \mid o_t)
\]

即仅根据当前观测选择动作。

但这通常不够，因为单次观测可能缺失重要信息。

更准确的形式是：

\[
\pi(a_t \mid h_t)
\]

其中 \(h_t\) 表示截至时间 \(t\) 的历史：

\[
h_t =
(o_1, a_1, o_2, a_2, \dots, o_t)
\]

也就是说，POMDP 中的策略通常需要结合历史观测和历史动作。

---

## 9. 为什么需要历史信息

历史信息可以帮助智能体推断当前不可见的真实状态。

例如：

```text
时刻 t-2：机器人看到杯子在桌面上
时刻 t-1：箱子被移动到杯子前面
时刻 t：杯子被完全遮挡
```

只看当前图像，机器人看不到杯子。

但结合历史，机器人可以推断：

> 杯子大概率仍然在箱子后面。

另一个例子：

```text
连续多帧图像显示门正在逐渐关闭
```

只看最后一帧，可能无法判断门的运动方向。

结合历史帧，就可以估计门的速度和运动趋势。

因此，POMDP 中常常需要：

- RNN
- LSTM
- GRU
- Transformer
- 显式 Memory
- 状态估计器
- Latent State Model

---

## 10. Belief State：信念状态

Belief State 是 POMDP 的核心概念。

记作：

\[
b_t(s)
\]

它表示：

> 在时间 \(t\)，智能体认为真实环境处于各个可能状态的概率分布。

因为智能体不知道真实状态，所以它维护的不是一个确定状态，而是对状态的概率估计。

例如机器人无法看到被遮挡的杯子，它可能认为：

\[
P(\text{杯子在箱子后面}) = 0.8
\]

\[
P(\text{杯子已被移走}) = 0.2
\]

这个概率分布就是 Belief State。

---

## 11. Belief State 不是普通观测

当前观测只表示智能体此刻看到什么。

Belief State 则综合了：

- 过去观测
- 过去动作
- 状态转移规律
- 当前观测
- 传感器噪声

它是对当前真实状态的综合估计。

可以概括为：

```text
历史 Belief
    +
上一动作
    +
当前观测
    ↓
新的 Belief
```

---

## 12. Belief State 的更新

Belief State 通常通过贝叶斯更新获得。

给定：

- 上一时刻信念 \(b_{t-1}(s_{t-1})\)
- 上一动作 \(a_{t-1}\)
- 当前观测 \(o_t\)

新的 Belief 可以写成：

\[
b_t(s_t)
\propto
O(o_t \mid s_t)
\sum_{s_{t-1}}
P(s_t \mid s_{t-1}, a_{t-1})
b_{t-1}(s_{t-1})
\]

这条公式可以拆成两步理解。

### 第一步：预测

根据上一状态估计和动作，预测当前状态：

\[
\bar{b}_t(s_t)
=
\sum_{s_{t-1}}
P(s_t \mid s_{t-1}, a_{t-1})
b_{t-1}(s_{t-1})
\]

回答：

> 根据我之前的判断和刚刚执行的动作，现在环境可能变成什么样？

### 第二步：校正

利用当前观测修正预测：

\[
b_t(s_t)
\propto
O(o_t \mid s_t)\bar{b}_t(s_t)
\]

回答：

> 当前传感器观测与哪些状态更加一致？

因此，Belief 更新的核心是：

```text
先根据动作预测
再根据观测修正
```

---

## 13. Belief State 如何把 POMDP 转换成 MDP

真实状态 \(s_t\) 对智能体不可见。

但如果 Belief State \(b_t\) 包含了所有历史信息，那么智能体可以把 Belief 当作新的状态。

策略可以写成：

\[
\pi(a_t \mid b_t)
\]

此时，POMDP 可以被转化为一个定义在 Belief Space 上的 MDP。

也就是说：

```text
不可见的真实 State
    ↓
维护 Belief State
    ↓
在 Belief 上进行决策
```

理论上，Belief State 是对历史信息的充分统计量。

---

## 14. POMDP 的完整交互过程

一个 POMDP 的交互流程如下：

1. 环境处于真实状态 \(s_t\)
2. 智能体无法直接看到 \(s_t\)
3. 环境通过观测模型产生 \(o_t\)
4. 智能体根据历史或 Belief 选择动作 \(a_t\)
5. 环境返回奖励 \(r_t\)
6. 环境转移到下一真实状态 \(s_{t+1}\)
7. 智能体获得新的观测并更新 Belief

流程可以表示为：

```text
真实 State s_t
      ↓
Observation Model
      ↓
Observation o_t
      ↓
History / Belief State
      ↓
Policy
      ↓
Action a_t
      ↓
Environment
      ↓
Reward r_t + Next State s_{t+1}
```

---

## 15. MDP 与 POMDP 的对比

| 对比项 | MDP | POMDP |
|---|---|---|
| 是否能看到真实状态 | 能 | 不能 |
| 智能体输入 | State | Observation、History 或 Belief |
| 是否需要状态估计 | 通常不需要 | 需要 |
| 是否依赖历史 | 不一定 | 通常需要 |
| 策略形式 | \(\pi(a \mid s)\) | \(\pi(a \mid h)\) 或 \(\pi(a \mid b)\) |
| 典型场景 | 理想仿真、完全信息环境 | 机器人、自动驾驶、视觉控制 |
| 主要困难 | 如何选择动作 | 如何估计状态并选择动作 |

---

## 16. POMDP 与 Latent State

现实机器人通常无法显式维护完整的概率分布 \(b_t(s)\)。

现代深度学习方法常使用一个神经网络隐状态，近似表示 Belief State。

记作：

\[
z_t
\]

或者：

\[
h_t
\]

它通常被称为：

- Latent State
- Hidden State
- Internal State
- Representation
- Memory State

这个潜在状态由历史观测和动作更新：

\[
z_t = f(z_{t-1}, a_{t-1}, o_t)
\]

它的目标是压缩历史中与未来预测和决策有关的信息。

---

## 17. POMDP 与 World Model

世界模型通常运行在 POMDP 环境中。

因为模型获得的是图像或传感器数据，而不是真实状态。

典型流程是：

```text
Observation
    ↓
Encoder
    ↓
Latent State
    ↓
Dynamics Model
    ↓
Predict Future Latent States
    ↓
Planner / Policy
    ↓
Action
```

世界模型需要解决两个问题：

### 17.1 状态推断

从不完整观测和历史中估计当前潜在状态：

\[
z_t = f(z_{t-1}, a_{t-1}, o_t)
\]

### 17.2 未来预测

根据潜在状态和动作预测未来：

\[
z_{t+1} \sim p(z_{t+1} \mid z_t, a_t)
\]

因此，世界模型不仅是一个状态转移模型，也常常包含状态估计机制。

---

## 18. POMDP 与 PlaNet、Dreamer

PlaNet 和 Dreamer 都使用潜在动力学模型处理部分可观测问题。

典型结构：

```text
Image Observation
      ↓
Encoder
      ↓
Latent Representation
      ↓
RSSM
      ↓
Future Prediction
```

RSSM 全称：

> Recurrent State-Space Model

它通过循环状态和随机潜变量结合：

- 历史动作
- 历史观测
- 当前观测
- 动力学预测

从而形成对当前环境状态的内部表示。

从 POMDP 角度看，RSSM 可以被理解为一种学习得到的 Belief State 近似。

它的作用不是简单“压缩图片”，而是：

> 从历史和当前观测中恢复一个适合预测未来和做决策的潜在状态。

---

## 19. POMDP 与 VLA

VLA 的输入通常是：

- 当前或历史视觉观测
- 语言指令
- 机器人本体状态
- 有时还包括历史动作

例如：

\[
\pi(a_t \mid o_t, l)
\]

其中：

- \(o_t\)：视觉观测
- \(l\)：语言指令
- \(a_t\)：机器人动作

但在部分可观测任务中，更合理的形式是：

\[
\pi(a_t \mid o_{\leq t}, a_{<t}, l)
\]

也就是利用历史观测、历史动作和语言指令。

VLA 面临的部分可观测问题包括：

- 物体被遮挡
- 任务阶段无法由单帧图像判断
- 需要记住之前执行过什么
- 需要判断物体运动趋势
- 需要保持长期任务进度

因此，带历史窗口、视频输入或内部记忆的 VLA，通常比单帧反应式策略更适合复杂长时序任务。

---

## 20. Reactive Policy 与 Memory-Based Policy

### 20.1 Reactive Policy

只依赖当前观测：

\[
a_t = \pi(o_t)
\]

优点：

- 结构简单
- 推理速度快
- 易于训练

缺点：

- 无法处理需要记忆的任务
- 容易在遮挡或观测歧义时失败

### 20.2 Memory-Based Policy

依赖历史或隐状态：

\[
h_t = f(h_{t-1}, o_t, a_{t-1})
\]

\[
a_t = \pi(h_t)
\]

优点：

- 能整合历史信息
- 能处理遮挡和动态环境
- 能估计速度、阶段和隐藏变量

缺点：

- 训练更加困难
- 长期记忆可能不稳定
- 误差可能随时间积累

---

## 21. POMDP 中的主动感知

在 POMDP 中，动作不仅可以改变环境，还可以帮助获取信息。

这称为：

> Active Perception（主动感知）

例如机器人不确定杯子后面是否有障碍物时，可以：

- 移动摄像头
- 改变观察角度
- 轻推物体
- 旋转物体
- 打开抽屉检查内部

这些动作可能不会立即完成任务，但可以降低不确定性。

因此，POMDP 中的动作可能同时具有两个价值：

1. 改变环境以接近任务目标
2. 获取更多信息以减少状态不确定性

这也是 POMDP 比普通 MDP 更复杂的重要原因。

---

## 22. POMDP 的核心困难

### 22.1 状态不可直接观测

智能体不知道真实环境状态。

### 22.2 观测存在噪声

传感器可能不准确、不稳定或受光照影响。

### 22.3 观测存在歧义

不同真实状态可能产生相同或相似观测。

### 22.4 需要长期记忆

当前决策可能依赖很久以前的信息。

### 22.5 需要处理不确定性

智能体不能只输出一个确定状态，而应考虑多个可能状态。

### 22.6 探索与信息获取

智能体有时需要先收集信息，再完成任务。

---

## 23. 常见误解

### 误解一：Observation 就是 State

错误。

Observation 是传感器获得的信息，State 是真实世界的完整情况。

### 误解二：POMDP 只需要看当前 Observation

错误。

当前观测通常不够，智能体往往需要历史信息或 Belief State。

### 误解三：Belief State 是一个确定状态

错误。

严格来说，Belief State 是对所有可能真实状态的概率分布。

### 误解四：Encoder 输出一定就是真实 State

错误。

Encoder 输出的是一种学习到的潜在表示，它只是在近似对决策有用的状态信息。

### 误解五：加入 RNN 就一定解决了 POMDP

错误。

RNN 只是提供了记忆机制，但它不保证学到正确、稳定或完整的 Belief State。

### 误解六：世界模型只负责预测未来

不完整。

在 POMDP 环境中，世界模型通常还需要根据历史和当前观测估计当前潜在状态。

## 24. POMDP 与后续知识的关系

| 后续概念 | 与 POMDP 的关系 |
|---|---|
| Value Function | 衡量某个状态或 Belief 的长期价值 |
| Q Function | 衡量某个状态或 Belief 下执行动作的长期价值 |
| State Estimation | 从观测中估计真实状态 |
| Kalman Filter | 线性高斯系统中的 Belief 更新方法 |
| Particle Filter | 用样本近似复杂 Belief 分布 |
| Latent State | 神经网络学习的内部状态表示 |
| World Model | 估计当前状态并预测未来状态 |
| RSSM | 用历史和观测维护潜在状态 |
| MPC | 根据当前状态估计规划未来动作 |
| VLA | 根据视觉、语言和历史信息输出动作 |

## 25. 一条完整的逻辑链

POMDP 与现代机器人学习的关系可以概括为：

```text
真实世界存在完整 State
        ↓
机器人无法直接获得 State
        ↓
只能获得不完整 Observation
        ↓
结合历史信息估计 Belief / Latent State
        ↓
World Model 预测未来
        ↓
Planner 或 Policy 选择动作
        ↓
机器人执行动作并获得新观测
        ↓
更新内部状态
```

---

## 26. 核心结论

POMDP 最重要的五个结论是：

1. **现实机器人通常无法直接获得完整 State，只能获得 Observation。**
2. **Observation 是真实状态的不完整、带噪声映射。**
3. **当前观测往往不足以决策，因此需要结合历史信息。**
4. **Belief State 表示智能体对当前真实状态的概率估计。**
5. **现代世界模型中的 Latent State、Memory 和 RSSM，本质上都在近似 POMDP 中的状态估计过程。**

可以把 POMDP 概括成一句话：

> POMDP 描述了智能体在无法直接看到真实状态时，如何利用观测、历史和状态估计进行连续决策，并最大化长期累计回报。
