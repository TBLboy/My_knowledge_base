# 机器人学习系统路线

这是一条面向 **机器人学习 / 具身智能算法工程师** 的系统学习主线。

它不是课程收藏夹，也不以“看完视频”作为完成标准。每个阶段都必须形成：

```text
知识理解 -> 最小代码实现 -> 实验观察 -> 阶段项目 -> 可复核验收
```

## 学习者基线

- 每天投入：约 1.5 小时。
- 建议节奏：每周学习 6 天，第 7 天补欠、复盘或休息。
- 数学：学过线性代数、微积分和概率统计，基础尚可，但需要结合模型重新激活。
- 编程：能够阅读和修改 Python 工程，尚不能稳定地从数据开始独立完成训练、验证和推理闭环。
- 已有经历：ROS2、Jetson Orin、LeRobot、GR00T、VLA、机器人数据和真实机器人项目。
- 主要缺口：通用机器学习、深度学习训练原理、PyTorch、视觉、Transformer、大模型、强化学习、模仿学习和实验工程之间缺少系统连接。

## 双设备约束

学习可能在两台设备之间切换：

| 设备 | 环境 | 主要用途 |
| --- | --- | --- |
| 台式机 | Linux，RTX 4090 24GB | 较大视觉训练、LoRA、策略复现、集中实验和性能分析 |
| 笔记本 | Windows，RTX 4060 8GB | 日常学习、基础实验、小模型训练、推理、代码和笔记 |

路线遵循以下规则：

1. 第一至第四阶段的必做作业必须能在 8GB 显存上完成。
2. 必须支持 CPU smoke test，避免环境或显卡问题完全阻断学习。
3. 24GB 显存实验标记为“4090 实验”，没有台式机时可以延后，不阻塞主线。
4. 数据集、模型权重、缓存、虚拟环境和大体积输出不提交 Git。
5. Git 中保存代码、配置、依赖声明、实验摘要和必要的小型图表。
6. Linux 和 Windows 均使用相对路径，不在代码中硬编码 `/home/...` 或盘符。
7. 每个实验提供 `device = cuda if available else cpu` 和可调 batch size。

## 每天怎么执行

默认 90 分钟分配：

```text
10 分钟：回忆昨天内容，回答一个闭卷问题
30 分钟：阅读或观看指定材料
40 分钟：写代码、运行实验或完成推导
10 分钟：记录结果、错误和下一步
```

当天没有完成时，不通过熬夜补齐。下一学习日先完成未结束的最小闭环，再继续新任务。

## 记录位置

路线文件保持稳定；当天产出放在：

```text
学习记录/YYYY.MM.DD/
├── 学习记录.md
├── exercises/
└── results/
```

其中：

- `学习记录.md`：概念回答、实验结论、疑问和复盘。
- `exercises/`：当天可运行代码。
- `results/`：必要的小型图表或指标摘要，不保存大模型和缓存。

## 推进方式

先完整执行第一个月。第 4 周验收后，根据实际速度、代码质量和薄弱项展开第 2 个月的逐日任务。二十八周总路线是稳定方向，逐日计划采用滚动细化。
