# 学习资料索引

## 使用规则

每个阶段只指定一个主资源。补充资源只在主资源解释不清或需要查 API 时使用，避免同时追多套课程。

资料优先级：

```text
官方教程 / 原始教材 / 维护中的代码仓库
  > 高质量大学课程
  > 个人总结与二次讲解
```

## 环境与跨设备建议

### 仓库中应保存

- `requirements.txt` 或 `environment.yml`。
- 源代码和测试。
- YAML/JSON 实验配置。
- README、结果表格和少量图表。
- 数据下载脚本或来源说明。

### 仓库中不应保存

- `.venv/`、Conda 环境。
- 原始数据集和缓存。
- Hugging Face、torch、wandb 缓存。
- 大型 `.pt`、`.pth`、`.ckpt`、`.safetensors`、`.onnx`、`.engine`。
- 每次运行产生的大量日志。

### 双设备兼容

- 首选 Python 3.11；具体项目如有上游限制则单独声明。
- Linux 和 Windows 分别创建环境，不同步环境目录。
- 用 `pathlib.Path` 管理路径。
- DataLoader 的 `num_workers` 从 0 开始验证；Windows 稳定后再增加。
- 8GB 显存先使用 224 或更低分辨率、小 batch、AMP 和 gradient accumulation。
