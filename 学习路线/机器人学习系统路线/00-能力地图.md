# 能力地图

## 最终目标

完成主线后，应具备以下能力：

1. 从原始数据构建可复现的数据集、训练集、验证集和测试集。
2. 使用 PyTorch 独立实现训练、验证、推理、checkpoint 和错误分析。
3. 能解释 CNN、Transformer、预训练、微调、强化学习和模仿学习的核心机制。
4. 能阅读 ACT、Diffusion Policy、OpenVLA、Dreamer、TD-MPC 等项目的训练入口和数据流。
5. 能对机器人策略实验进行数据检查、指标设计、失败归因和部署约束分析。
6. 能在工作站训练，在 8GB 笔记本或 Jetson 上完成受约束推理和性能评估。
7. 最终形成至少两个可展示项目，而不只是教程 Notebook。

## 知识依赖链

```text
Python 工程与数值计算
  -> 线性代数 / 微积分 / 概率 / 优化
  -> 经典机器学习与可靠评估
  -> 神经网络、反向传播和 PyTorch
  -> CNN、视觉数据和迁移学习
  -> Attention、Transformer 和预训练模型
  -> MDP、价值学习、策略优化和模型式 RL
  -> 行为克隆、序列策略、ACT、Diffusion Policy
  -> 多模态、VLA、世界模型和跨本体数据
  -> 训练工程、推理优化、ROS2 / Jetson 集成
```

## 八个能力域

### 1. 数学与建模语言

必须掌握：

- 向量、矩阵、张量、广播和常见矩阵运算。
- 导数、偏导、梯度、链式法则。
- 概率分布、期望、方差、条件概率、最大似然。
- 损失函数、正则化、梯度下降和学习率。

目标不是进行复杂证明，而是能从公式追踪 shape、优化对象和假设。

### 2. 数据与经典机器学习

必须掌握：

- 数据清洗、特征、标签和数据划分。
- 线性/逻辑回归、树模型和基础聚类。
- 过拟合、交叉验证、数据泄漏、类别不平衡。
- accuracy、precision、recall、F1、ROC-AUC、MAE、RMSE。

这部分决定后续深度学习实验是否可信。

### 3. 深度学习训练

必须掌握：

- `Dataset`、`DataLoader`、`nn.Module`、loss、optimizer。
- forward、backward、梯度清零、参数更新。
- train/eval 模式、随机种子、checkpoint、日志。
- 初始化、归一化、激活、正则化和学习率调度。

### 4. 视觉与表征学习

必须掌握：

- CNN、感受野、特征层级和残差连接。
- 分类、检测、分割三类任务的输入输出差异。
- 数据增强、迁移学习、冻结/解冻和错误分析。
- ViT 与 CNN 的主要差异。

### 5. Transformer 与大模型

必须掌握：

- token、embedding、位置编码、self-attention、causal mask。
- encoder、decoder、预训练、指令微调和 LoRA。
- 推理中的 KV cache、量化、吞吐和显存约束。
- 语言模型、VLM 和 VLA 的输入输出边界。

### 6. 强化学习与控制

必须掌握：

- MDP/POMDP、return、value、Q、Bellman equation。
- DQN、policy gradient、actor-critic、PPO 的问题与机制。
- on-policy/off-policy、探索、replay buffer、target network。
- model-free、MBRL、MPC 和 world model 的关系。

### 7. 模仿学习与机器人策略

必须掌握：

- 行为克隆、covariate shift、DAgger。
- 轨迹、episode、observation、action、action chunk。
- ACT 的 CVAE 和 chunking。
- Diffusion/flow 动作生成和多峰动作分布。
- 数据归一化、时序对齐、控制频率和评测 protocol。

### 8. 工程与部署

必须掌握：

- Git、环境锁定、配置管理和可复现实验。
- mixed precision、gradient accumulation、profiling。
- ONNX/TensorRT 的基本转换和数值一致性检查。
- ROS2 节点边界、传感器适配、动作安全限制和日志。

## 明确不做

- 不按顺序学完所有数学课程再开始写模型。
- 不从零预训练大语言模型或大型 VLA。
- 不把调用 API、跑通 Notebook 或复述论文摘要当作掌握。
- 不追逐大量模型名称；优先掌握可迁移的核心机制。
- 不在没有数据和评测协议时宣称模型改进有效。
