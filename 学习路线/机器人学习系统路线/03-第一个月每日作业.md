# 第一个月每日作业

## 本月目标

24 个学习日后，你必须能够独立完成：

```text
加载数据 -> 定义模型 -> 训练 -> 验证 -> 保存 -> 恢复 -> 推理 -> 错误分析
```

本月所有必做实验必须可以在 Windows RTX 4060 8GB 上完成，也可以在 Linux RTX 4090 上执行。

## 第 1 周：Tensor 与梯度

### Day 1：建立学习工程

**10 分钟**：写下你理解的训练集、验证集、模型、loss、optimizer。

**30 分钟**：阅读 PyTorch `Learn the Basics` 首页和 Tensors。

**40 分钟**：创建当天目录，完成：

- tensor 创建、reshape、transpose、索引。
- CPU/GPU 移动。
- 打印 shape、dtype、device。
- 使用 `pathlib.Path`，禁止硬编码系统路径。

**10 分钟输出**：记录 Linux 和 Windows 可能不同的部分。

**完成条件**：能解释 `[B, C, H, W]` 每个维度。

### Day 2：广播与矩阵乘法

- 阅读 tensor operations。
- 练习 element-wise multiplication、`matmul`、broadcasting。
- 手算并验证 5 组输出 shape。
- 写一个函数检查矩阵乘法输入是否合法。

**闭卷题**：`[32, 128] @ [128, 10]` 的输出是什么？

### Day 3：NumPy 线性回归

- 生成带噪声的 `y = 3x + 2` 数据。
- 用 NumPy 写预测、MSE 和梯度下降。
- 绘制 loss 曲线和拟合直线。
- 分别尝试过大和过小学习率。

**输出**：三种学习率的结果表及原因解释。

### Day 4：PyTorch autograd

- 阅读 Automatic Differentiation。
- 用 tensor 和 autograd 重写 Day 3。
- 查看 `.grad`、`requires_grad`、`grad_fn`。
- 故意漏掉梯度清零，观察结果。

**完成条件**：能解释为什么梯度会累积。

### Day 5：`nn.Module` 与 optimizer

- 使用 `nn.Linear` 和 `torch.optim.SGD` 重写线性回归。
- 打印 `model.parameters()`。
- 保存和加载 `state_dict`。
- 确认加载后预测一致。

### Day 6：本周复盘实验

- 不看旧代码，重新写一个最小线性回归训练脚本。
- 限时 45 分钟。
- 剩余时间检查可复现性并写本周总结。

**周验收**：解释 parameter、gradient、loss、optimizer 的关系。

## 第 2 周：分类与完整训练循环

### Day 7：分类数学

- 复习 sigmoid、softmax、logits 和交叉熵。
- 手算两个二分类和一个三分类例子。
- 用 PyTorch 验证结果。
- 比较 `CrossEntropyLoss` 输入 logits 与错误输入 softmax 的差异。

### Day 8：Dataset 与 DataLoader

- 阅读 PyTorch Datasets & DataLoaders。
- 加载 FashionMNIST。
- 检查一个 sample 和一个 batch。
- 打印 image/label shape、dtype、范围和类别分布。
- Windows 上先设置 `num_workers=0`。

### Day 9：构建 MLP

- 阅读 Build the Neural Network。
- 实现 `Flatten -> Linear -> ReLU -> Linear`。
- 手算每层 shape 和参数量。
- 用随机 batch 完成 forward。

### Day 10：训练函数

- 写 `train_one_epoch`。
- 包含 `model.train()`、forward、loss、backward、step、zero_grad。
- 每若干 batch 输出平均 loss。
- 先只训练 1 个 epoch。

### Day 11：验证函数

- 写 `evaluate`。
- 使用 `model.eval()` 和 `torch.no_grad()`。
- 计算平均 loss 和 accuracy。
- 解释验证时为什么不更新参数。

### Day 12：完整训练与 checkpoint

- 训练 5 个 epoch。
- 保存 best validation checkpoint。
- 重新启动脚本加载 checkpoint。
- 对 10 张样本推理并记录错误。

**周验收**：脱离教程写出完整训练和验证循环骨架。

## 第 3 周：fastai 与高层训练抽象

### Day 13：fastai 快速分类

- 阅读 fastai quick start 的视觉分类部分。
- 跑通一个小型图像分类例子。
- 调用 `show_batch`、`fine_tune`、`predict`。
- 记录每个高层调用替代了哪些 PyTorch 代码。

### Day 14：DataBlock

- 阅读 DataBlock tutorial 的前半部分。
- 写出 `blocks`、`get_items`、`splitter`、`get_y`、`item_tfms`。
- 使用 `summary()` 检查数据管线。
- 故意制造一个错误标签函数并定位问题。

### Day 15：Learner

- 阅读 `Learner`、training loop 和 PyTorch interop 对应章节。
- 画出 `dls/model/loss/opt/metrics/callbacks` 关系图。
- 用 `learn.show_training_loop()` 观察事件结构。

### Day 16：迁移学习

- 使用小型预训练视觉模型。
- 比较冻结训练和 `fine_tune`。
- 记录训练时间、验证指标和显存。
- 解释 freeze/unfreeze。

### Day 17：指标与错误分析

- 生成 confusion matrix。
- 查看 top losses。
- 分类错误原因：标签、图像质量、类别相似、模型置信度。
- 提出一个可证伪的改进假设。

### Day 18：fastai 与 PyTorch 对照

- 选择同一分类任务。
- 列出纯 PyTorch 与 fastai 的数据、模型、loss、optimizer、训练和推理对应关系。
- 不要求指标完全相同，但必须解释默认设置差异。

**周验收**：能够使用 fastai 快速实验，同时指出底层 PyTorch 训练循环在哪里。

## 第 4 周：可靠训练与阶段项目

### Day 19：可复现性

- 设置 Python、NumPy、PyTorch 随机种子。
- 连续运行两次小实验。
- 比较结果差异。
- 记录 deterministic 设置的代价和边界。

### Day 20：训练诊断

人为构造并修复以下问题：

- 学习率过大。
- 忘记 `zero_grad`。
- 标签范围错误。
- train/eval 模式错误。
- 数据归一化错误。

每个问题记录：症状、定位方法、根因、修复证据。

### Day 21：项目数据与 baseline

- 项目选择 FashionMNIST 或 CIFAR-10。
- 固定数据划分、随机种子和指标。
- 建立最小 MLP 或 CNN baseline。
- 保存配置和第一组结果。

### Day 22：一次受控改进

只选择一个变量：

- 网络结构。
- 数据增强。
- optimizer。
- 学习率。
- 正则化。

保持其他条件不变，比较结果。禁止同时改多个主要变量。

### Day 23：错误分析与推理脚本

- 输出 confusion matrix 和错误样例。
- 写独立推理入口。
- 加载 checkpoint，对单张或一批输入预测。
- 检查 CPU 与 GPU 推理接口均可运行。

### Day 24：阶段答辩

不看资料回答：

1. 为什么训练使用 mini-batch？
2. logits 为什么通常直接交给交叉熵？
3. `model.train()` 和 `model.eval()` 改变什么？
4. 为什么验证集不能参与参数选择之后的最终无偏评估？
5. loss 降而 accuracy 不升可能是什么原因？
6. checkpoint 至少需要保存什么？
7. fastai 的 `Learner` 管理了哪些对象？
8. 如何判断一次改进是否可信？

随后从空文件写出训练循环关键代码，并运行项目最终版本。
