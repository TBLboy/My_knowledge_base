### 1. 切黄瓜 / 切豆腐机器人流程

**记录确认的工程内容：**

- 机器人流程由状态机/Orchestrator 组织，多个技能通过 ROS 2 Action 暴露。
- 切豆腐主流程包含取刀、视觉对刀、水平切割、人工旋转、再次对刀、垂直切割、抓料摆放和倒酱料等阶段。
- 切黄瓜存在独立流程：左臂握持黄瓜、准备切割姿态、水平切割、释放黄瓜。

- 视觉链路使用 RealSense、SAM3、姿态估计；机械臂控制通过 xCore SDK；人工介入通过操作文件/确认信号实现。
- 切豆腐主线已记录为 7 阶段并完成硬件测试：取刀、准备、第一次切割、人工旋转、第二次切割、再次旋转/准备、垂直切割。

### 4. 模型训练、GR00T 微调与机器人策略部署

**记录确认的工程内容：**

- 将原始机器人数据从 v2.1 转换为 LeRobot v3.0 数据集。
- 已记录数据规模：148 个有效 episode、47,250 帧、30 FPS、3 路相机、右臂 + O6 连续 13D 状态/动作。
- 使用 GR00T N1.7 约 3B 基础模型，配置右臂 7D + O6 手 6D embodiment，并生成 normalization stats。
- 通过 batch=1、gradient accumulation、paged AdamW 8-bit、gradient checkpointing、workers=0 等方式适配显存约束。
- 完成约 30,000 step 正式重训，constant LR=5e-5、warmup=1500、约 5.3 次全量数据 pass，最终 loss 约 0.038。
- 训练集 open-loop 验证：4 条轨迹平均 MSE=23.62、MAE=1.15；单轨迹相对旧 checkpoint 的 MSE 由 717.38 降至 13.73。
- 完成 GR00T 代码工程地图，梳理微调、策略推理、真机 adapter、评估、部署、扩展和入口文件。
- 完成远端部署准备，记录 runtime bundle/service_host 模式和远端部署手册。
- 当前边界：未见轨迹泛化和真机闭环仍需单独验证，不能把训练集 open-loop 结果表述成真机部署成功。

- LeRobot/GR00T 数据、配置、训练、checkpoint 和评估闭环
- 自定义 embodiment 与多模态机器人动作维度映射
- 低显存训练配置和训练稳定性排查

1. **老板电器炒菜机器人：**最新、系统复杂度高，适合展示策略、感知、控制、SDK 与硬件集成。
2. **GR00T/LeRobot 微调与部署：**有明确数据规模、训练步数和 open-loop 指标，适合展示具身智能算法工程能力。
3. **切黄瓜/切豆腐机器人：**能展示从动作到完整任务闭环的长期成长与机器人控制基础。
4. **数据平台/QC/标注系统：**能展示后端、数据工程、平台架构和复杂业务落地能力。
5. **机器人控制 APP：**能展示产品化、跨端、API 协议和现场操作闭环。
6. **Vibe Coding 框架：**差异化强，但需根据目标岗位决定是否作为主项目或补充项目。

## 五、必须在下一轮向用户确认的事实

- 每个项目的真实时间范围和项目名称。
- 用户在团队中的正式身份、团队规模和直接协作者。
- 用户独立负责、主导、深度参与和仅了解的边界。
- 可公开的代码、截图、演示、部署环境和实验数据。
- 项目是否真实上线/现场使用/真机运行，以及验证范围。
- 可写入简历的量化指标和不宜公开的内部信息。
- 目标岗位优先级：机器人控制、具身智能算法、数据/平台、Android APP、AI Agent 工程等。

## 长程交付阶段

1. **第一阶段：项目探索与精华材料**
   - 一次详细探索一个项目。
   - 提取项目背景、个人职责、技术动作、难点、结果、证据、可包装角度和待确认问题。
   - 每个项目形成一份精华材料，全部保存到 `个人简历/`。
2. **第二阶段：简历雏形**
   - 从精华材料提取技能和项目价值。
   - 按应届生 HR 视角拆解、组合和包装项目经历。
   - 形成第一版可投递简历雏形，不追求一次完成最终措辞。
3. **第三阶段：专业美化与最终版**
   - 针对每个项目进行语言压缩、成果前置、关键词优化、岗位匹配和表达强度调整。
   - 形成可直接放入简历的项目经历版本。

## 应届生写作口径

- 重点展示学习速度、技术迁移、独立交付、复杂问题解决、工程闭环和成长潜力。
- 不套用多年社招候选人的管理规模、商业营收和组织影响力叙事。
- 可以突出“独立完成”“全流程负责”“核心模块主导”“从 0 到 1 搭建”等应届生高价值信号，但必须有项目事实支撑。
