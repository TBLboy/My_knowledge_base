## 1. 项目定位

面向机器人展会/演示场景，参与开发视觉引导的切黄瓜机器人系统，并与切豆腐、抓料、倒酱等动作链形成上层任务流程。

切黄瓜主流程：

```text
系统就绪
 → 左臂握持黄瓜
 → 准备黄瓜切割位姿
 → 水平切割
 → 左臂释放黄瓜
```

项目整体还包含右臂取刀、豆腐切割、抓料摆放和倒酱等并行/独立流程。

## 3. 系统架构

- 右臂持刀，左臂执行黄瓜握持、抓料和倒酱等辅助动作。
- 视觉使用 RealSense + SAM3 + pose estimator。
- 机器人控制通过 xCore SDK。
- 各个 Skill 通过 ROS2 Action 接口暴露。
- Orchestrator 通过 tick 驱动状态机顺序调用。
- 人工介入通过文件/确认信号完成。

主要 Action：

- `handle_approach`：取刀。
- `tofu_prepare`：豆腐切割准备。
- `tofu_cut_round`：豆腐水平切割。
- `tofu_vertical_cut`：豆腐垂直切割。
- `cucumber_hold`：黄瓜握持与释放。
- `pick_place`：抓料摆放。
- `sauce_pour`：倒酱。

## 4. 项目难点

| 难点 | 工程处理方向 |
| --- | --- |
| 多个机器人动作需要按顺序执行 | 使用 Orchestrator + ROS2 Action 状态机 |
| 左右臂承担不同职责 | 将右臂持刀和左臂辅助操作拆为不同 Skill |
| 视觉目标和动作执行存在异步性 | 使用 Topic 获取视觉结果、Action 管理动作阶段 |
| 展会演示需要人工介入 | 用显式等待信号和阶段状态支持人工旋转/继续 |
| 多项目动作链共存 | 将黄瓜、豆腐、抓料、倒酱拆为可复用流程节点 |
| 真实硬件存在连接/执行波动 | 通过 preflight、Action result 和阶段反馈进行验证 |
